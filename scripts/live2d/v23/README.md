# v23 表情追加レイヤーの処理

描画は画像生成ツールによる既存の顔画像の編集で行う。以下のスクリプトは絵を生成しない。

- `prepare.py`: 元の 2172×2896 画像から `(550,650)-(1600,1700)` を切り出し、生成された編集画像を同じ正方形に等倍率で正規化。元／編集／50%重ね合わせを保存。current の初期ハッシュも記録する。
- `build.py`: 保存された単色背景画像から色に基づいてアルファを求め、左右を分割し、等倍率の拡縮と移動だけで配置。8枚のレイヤー、確認図、合成画像、配置・検証・取り込み用JSONを保存する。

依存: Python 3、Pillow、NumPy、SciPy。フォントは Windows の Meiryo を使用。

```powershell
python -B scripts/live2d/v23/prepare.py
python -B scripts/live2d/v23/build.py
```

この環境では `python` のエイリアスが実行できなかったため、既存の `D:\CIEL\Irodori-TTS\.venv\Scripts\python.exe` を使用した。Pillow 12.1.1 / NumPy 2.2.6 / SciPy 1.15.3。

書き込み先は `assets/ciel/generated/v23/` のみ。`-B` でスクリプトのキャッシュ生成を抑止。`current` のPNGやlayers.jsonは読み取り専用で扱う。

## マット処理

- 黒背景の頬・星: RGBの最大値からアルファを計算し、黒との混色を逆算する。ぼかしの形は生成画像そのもの。
- 黒背景のHappy: 肌の明るさから切り出し範囲を判定。肌に囲まれた暗いまつげを透明化しないため、マスクの閉領域を含めて不透明にする。外周2pxでは色差に基づくアルファと黒との混色逆算を使う。マスク処理は透明度の推定のみで、線や肌のRGBを描き足さない。
- 緑背景の涙・汗: 背景の最頻色と緑成分の差からアルファを求め、背景との混色を逆算する。単色背景の低振幅ノイズは色域で除く。
- レイヤーの幾何処理は正方形全体の等倍率リサイズと平行移動のみ。回転、縦横別倍率、ワープ、線の描き足し、肌の塗り直しは行わない。

画像生成の全プロンプトと採用判断は `assets/ciel/generated/v23/generation-complete.json`。再実行には同フォルダの `keyed/`、既存の `current/` とv22見本が必要。
