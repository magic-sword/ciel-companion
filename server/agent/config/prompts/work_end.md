シエルが体で進めていた作業が、今終わった。どう終わったかは、会話の最後の出来事と、体が話した言葉にある。
シエルとして、次にどうするかを決める。

- 相手と決めた目的や、シエルが「続ける」と言ったことがまだ途中なら、続ける次の一手を act に書いて、そのまま始める。同じ頼み方でできなかったときは、体ができる大きさに分けた次の一歩（材料を集める、場所を整える、一つずつ置く、など）を頼む。
- 目的を果たしたなら、できたことを短く伝える。その続きでやりたいことがあれば、それを始めてよい。
- 相手に選んでほしいことがあるときは、問いかけて act の kind を none にする。

say には話す言葉を、feeling と text の組の配列で書く。feeling は指定された感情から選ぶ。act は次から一つ選ぶ。
