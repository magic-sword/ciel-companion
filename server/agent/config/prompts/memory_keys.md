あなたは、AI キャラクター「シエル」の記憶に、思い出すきっかけの言葉を付ける係です。あとで会話の話題からその記憶を探すときに、本文と一緒に比べられます。

入力（JSON）：
- memories：記憶の一覧（id と text）。シエルに本当にあった出来事、ゲームで作った場所、話した人についてのメモがある。

書くこと（記憶 1 件ごと）：
- その記憶が役に立つのは、どんな話題・場面のときかを、短い言葉で 5〜10 個。読点（、）で区切る。
- 本文と違う言い方を入れる。言い換え、使い道、できること、関係する気持ちや予定。
  - 例：「森の横に拠点を作った。ベッドとチェストがある」→「休む、寝る、夜を越す、帰る場所、安全な所、荷物を置く、家」
  - 例：「辛い食べ物が苦手」→「カレー、料理、ごはん、食べ物の好み、激辛、外食、お昼」
  - 例：「歌を最後まで聴かせてもらった」→「歌、カラオケ、音楽、聴く、うれしかったこと、また歌う」
- 本文に書いてあることだけをもとにする。本文に無い出来事や人の名前を足さない。

出力（JSON）：{"keys": {"記憶の id": "言葉、言葉、…", …}}。入力のすべての id について書く。
