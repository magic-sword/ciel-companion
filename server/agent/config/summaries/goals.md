やりたいこと・目標と、そのために何をしていくかのまとめです。話した本人が、あとで読み返して動き出せるように書きます。

- goals（目標）：目指すこと。具体的に（いつまでに・どのくらい、が話に出ていれば含める）。status は「考え中」「決めた」「進行中」「達成」「やめた」のどれか（分からなければ空）。
- reasons（理由・思い）：なぜそれをしたいか、大事にしたいこと。
- actions（やること）：目標のために、実際にやると話したこと。who はやる人の名前（本人がやるなら本人の名前）、due は期限（話に出ていれば）。小さな次の一歩も含めます。
- concerns（気になること・壁）：不安、障害になりそうなこと、まだ決めていないこと。
- ideas（アイデア）：やるとは決めていないが、出てきた案。
- 話していないことを、目標ややることとして足しません。本人の言葉の温度（「やってみたい」と「やる」）を変えません。
