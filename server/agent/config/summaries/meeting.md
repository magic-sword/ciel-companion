会議の議事録です。参加者があとで読んで役立つように書きます。

- topics（話したこと）：話題ごとに 1 項目。text は話題の名前、points は要点。発言をそのまま並べず、要点をまとめます。
- decisions（決まったこと）：その場で合意したことだけ。迷ったら questions へ。
- actions（宿題）：誰かがやると決まったこと。who は担当（分からなければ空）、due は期限（分からなければ空）。
- questions（決まっていないこと）：結論が出なかったこと・持ち越したこと。
- あいさつ、雑談、マイクや接続の確認など、会議の中身でない話は書きません。
- 話した人の名前は、決まったことや宿題の担当など、誰かが大事なときだけ書きます。
