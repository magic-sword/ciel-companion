# bg-v1：工房2階サロンの会話背景

2026-10-16 制作。昼・夕方・夜の3枚を同じ部屋・同じ視点で作成した。納品画像はすべて **1080×1920、9:16、RGB PNG**。人物・文字・ロゴ・UIは含めず、背景自体にはぼかしを加えていない。

| --- | --- |

| [salon_dusk.png](salon_dusk.png) | 茜色の空、対岸プラントのシルエット、水面の夕映え、点灯した暖色ペンダント。 |
| [salon_night.png](salon_night.png) | 夜の運河と街の灯り。暖色照明を落とし、ガラス内のシアンのサーバー光を残した。 |

設定は `inputs/garage-setting.md` の3.3・3.4章を中心に、無垢パイン材の床・作戦テーブル、パノラマ連窓、ペンダント、モンステラとフィカス、木の本棚、強化ガラス越しの光量子ラック、小さな犬用ベッド風の充電椅子を描いた。外観参考は `inputs/garage-exterior.png`、塗りと採光の参考は `inputs/style-terrace-lounge.png`。文字・空間AR・天板投影などは今回の背景に描いていない。

画像生成ツールで昼の初稿を作成し、現画面への50%重ね合わせで確認。本棚が端末の左右切り取りで消えやすかったため、本棚と充電椅子を内側に寄せる編集を1回行った。昼は計2案で、再生成・修正は上限4回以内。採用した昼画像を直接の参照画像として、夕方と夜をそれぞれ時間・照明だけの編集で作成した。夜はさらに暖色照明を抑える編集を1回行った。

生成原画は各941×1672。納品時には中央基準で元画像の横幅約0.5px相当だけ比率を整え、Lanczosで約1.15倍に拡大して1080×1920に揃えた。ネイティブ1080×1920の生成原画ではない点は留意。原画は `sources/`、編集プロンプトと生成元の記録は [generation_log.json](generation_log.json)、寸法処理は [image_metadata.json](image_metadata.json) に保存。

構図の確認結果：

- 立っている人の目線を意図した、水平で奥へ抜ける視点。窓は左奥、ガラスのサーバー室は右奥、中央は落ち着いた壁面と床で奥行きを確保した。
- 中央上部に本棚・サーバーの発光部・文字を置かず、顔の後ろは低密度の壁面。ペンダントは左右の上方に分けた。昼の壁の木漏れ日は淡く、ぼかし後の表示案で顔周辺を圧迫しないことを確認した。
- 下30%は家具のない陰になった床を中心とし、細かい小物や文字を置いていない。床板の線と穏やかな反射は残る。
- 現画面は540×1170で9:16より縦長。高さに合わせて表示すると左右が各約9%切れるため、その切り取りでもサーバー・本棚・充電椅子の存在が読めることを確認した。机と植物の一部、本棚と椅子の外縁は切れる。
- 3枚を並べ、窓枠、梁、ペンダント、机と椅子、ガラス枠、本棚、充電椅子、床板の主要な線が同じ位置にあることを目視で確認した。生成編集のため、葉や木目などの微細な描画まで画素単位の一致を保証するものではない。
- 背景に人物・看板・本の背文字・ロゴ・UI・ホログラムがないことを目視確認した。

気になる点として、現画面ほどシエルを大きく表示すると、家具の多くは身体に隠れ、時間帯の違いは主に左右の窓・光色・上部照明に出る。これは今回の背景用途で想定される見え方。さらに縦長の端末では本棚や充電椅子の見える量が減る。現画面比率の表示案は静止PNGと簡略UIによる確認であり、UnityのLive2D位置・シェーダー・実際のぼかし処理を実行したスクリーンショットではない。UIの文字コントラストは下部グラデーションにも依存する。

確認図は [build_previews.py](build_previews.py) をリポジトリのルートから実行して再作成できる。Unityへの取り込みは実施していない。`unity/Assets/Resources/CielUI/` の48ファイルはSHA-256で前後比較し、変更がないことを確認。検証結果は [validation.json](validation.json) に記録した。

確認図（`previews/`）・入力のコピー（`inputs/`）・試しに描いた絵（`sources/*_attempt_*`）は、採用後に Git の外（`.local/archive/ui-generated/bg-v1/`）へ移した。
