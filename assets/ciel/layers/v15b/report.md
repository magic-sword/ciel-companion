# v15b 体まわり修正報告

2026-10-12。v15を残し、首輪・胴の幅・後ろファーを修正した。2172×2896のRGBA PNG 55層、manifest、layer-state、層一覧、再現スクリプト、PSD作成ラッパーを用意した。画像生成は **4回／上限20回**。

## 変更したこと

首輪から肩へ伸びていた黒い細い紐は、首輪の層ではなくBodyに描かれていたため、Bodyの再生成で除去した。首輪は前後の帯・金具・黒い当て布・丸飾りを一体で生成してから既存5層に分け、同じ輪の形と陰影を保った。後帯には首の奥の暗い内壁を持たせ、前帯の下、金具の下、飾りの根元にも下地を補った。

胴は胸下から腹部・腰にかけて幅を広げ、急に内側へ落ち込む輪郭を緩めた。トップス、腰帯、スカートも同じ連続した変形で合わせた。生成だけでは腰の細さが十分に変わらなかったため、採用画像の胴下部を数値で補正し、左右の上着も下側の開きを調整した。肌は赤みを抑えた白磁の色にし、立体を示す陰影は残した。年齢感は見た目の判断であり、数値で年齢を判定したものではない。

新設したFur_Backは首・体の後ろを通る一続きの白い襟。Hair_Backの上、Bodyの下（z=5）に置き、両端をOuter_L/R内の肩ファーに重ねた。首まわりを盛り上げすぎない高さに調整し、素肌の肩を残した。

呼吸・傾きのため、広げた腰の左右を上着の下まで補い、首の上端にも顔で隠れる24px以内の余白を補完した。顔のPNGには手を加えていない。

## 検証結果

既存54層の名前・相対順・z・表示状態・クリップ設定を維持し、Fur_Backだけを追加した。顔まわり43層を含む45層はv15とSHA-256が一致。今回の入力に使ったv15関連・原画98ファイルのハッシュも一致した。書込みは指定されたv15bの3ディレクトリ内のみ。

体まわり12層の個別移動と、後ろ髪を除いた体一式の移動を、上下左右・斜め8方向の±15px、計104ケースで検査した。通常表示では検査範囲の内部に新しい透明穴は0px。髪・耳・影の被覆を除く厳しい検査では、後帯を右下へ15px単独移動した場合だけ首との境界に5pxの穴が残る（下記参照）。

Fur_Backと各Outerをそれぞれ±15px動かす81通りの相対配置でも、肩ファーとの重なりは両側とも維持。最小重なりは画面左21,082px、画面右29,452pxだった。

検査条件はα>200、通常時の輪郭から32pxより内側、x=350〜1849・y=1200〜2859。これはPNGの並進と被覆の検査であり、輪郭の自然さやCubismの変形を保証する検査ではない。数値は[validation.json](validation.json)に保存した。

## 残る問題と引継ぎ

- 髪を非表示にし、首輪の後帯だけを右下へ15px移動すると、首の左境界付近（x=1025〜1027、y=1358〜1359）に計5pxの透明部が出る。通常の髪あり表示と体一式の移動では出ない。首輪前後を独立して平行移動すると輪の段差も見えるため、リグでは首輪の共通親で接続を保つ必要がある。
- Choker_Insideは黒い当て布、Choker_Pendantはタブと丸飾りに担当を整理した。当て布を丸飾りの揺れに追従させず、飾りは接続根元を固定して揺らす。Fur_Backは左右Outerと共通の上着の親で動かす。
- 胴・トップス・腰帯・スカートは既存のBody一層内。今回の指定通り分割を増やしていないため、各部の独立した動きはメッシュ・デフォーマで扱う。
- Cubism・Unity内での呼吸、体の傾き、PSD差し替えは未検証。素材と確認図までの成果物。
- [psd-manifest.json](psd-manifest.json)のoutは`assets/ciel/psd/ciel-v15b`。[PSD作成ラッパー](../../../../scripts/live2d/v15b/build_psd_with_state.py)を用意した。今回は指定された書込み先にPSD出力先が含まれないため、PSD書出しは実行していない。

再現手順は`build.py` → `handoff.py` → `verify.py`の順。スクリプトは同時実行せず、最終確認図は`proofs/`直下を見る。途中の確認図は`proofs/drafts/`へ分けて保存した。
