# 背面素材の生成指示

参照画像はマスターの着用図とv57の中立姿勢。出力は透過背景の後ろ襟・背面布の一体素材。

- カメラは正面・正投影。身体と上着の前側が透明になったと仮定した背面部材を描く。後ろ向きのキャラクターを描かない。
- 首の後ろでつながる白い毛皮の襟を、左右の肩から連続する浅いU字の帯として描く。前に垂れた二本のファーだけにしない。
- 襟の下から短丈の裾まで、青い背中の中央と肋骨へ回る左右の布を描く。身体に隠れる中央を透明にしない。肩・脇の接続にも十分な隠し代を持たせる。
- マスターの毛束、淡い紫の線と影、青い布の色・質感を合わせる。肌、髪、手、腕、白いインナー、前身頃、袖、装飾、文字を含めない。
- 自然な布の流れと折れ目を持つ、完成した部材全体を描く。

生成原本は`rear-garment-generated.png`。ライブラリ側の原本も保持している。後処理は孤立したアルファのごみ除去、等方拡大、平行移動のみ。配置値は`../generation-provenance.json`に記録する。
