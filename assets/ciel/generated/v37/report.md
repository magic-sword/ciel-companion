# 困り顔：v37採用版

基準は v22/expressions/troubled.png。採用済み73層のモデルに、困り眉・ためらった口・見本の汗の3層を追加する。素材の新規生成はせず、顔全体の位置関係を保ったまま口・汗を画像編集で切り出し、眉は見本の輪郭を清書した。

`ParamTroubled` で眉・口・汗・目元を切り替える。上瞼は見本と通常モデルのまつげ上端を測り、左右別の曲線で合わせた。しょんぼりより開いた目を保ち、虹彩とハイライトは縦0.95倍・下へ18px移動する。上の白い隙間を避けるため虹彩の上端だけを最大18px延長する。初回は下瞼の形を通常と同じにしていたが、最新候補では肌色の下瞼と旧線を非表示にし、白目の境界に合わせた既存のにこにこ用の線を共用する。閉眼・笑い目・他の表情のキーは維持する。

耳は `ParamEarFold=1`、`ParamEar=0` で既存の折れ耳を共用する。汗は専用のパーツを使い、旧Sweatパーツを非表示にして二重表示を避ける。発話時は既存の開口パーツを使う。

正式モデルは `assets/ciel/rig/ciel.cmo3`、最新の比較・検証は `assets/ciel/rig/proofs/troubled-v37-lower-lid/`。初回の `troubled-v37/` は調整前の記録。[全表情の下まぶたの見直し](../../rig/proofs/lower-lid-review/README.md)に必要性と判断をまとめた。正式モデル・現行素材・Unity更新用パッケージへ反映済み。Unityのモデル自体は未適用。旧候補一式は `.local/troubled-adoption/adopted-draft/` へ退避した。
