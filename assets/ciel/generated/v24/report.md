## 編集内容

**耳**：元の層を緑背景に合成して参照画像とし、組み上げた頭部も参照して根元の続きを画像編集で描いた。Outer の元の実質的な切り口は R が約y586、L が約y611。新しい下端は R がy772、L がy757で、それぞれ約186px・146px下までつながる。Inner の下端は元より R が169px、L が147px延びている。

Base は下端ではなく上端に切り口があったため、元の下側の毛を残して上へ R が113px、L が155px補った。正面で見える毛並みを保持するため、元画素を残し、同じ側の既存 Base の不透明部分を Outer にも切り出してつないだ。生成した根元と、既存の層順で組み上げた耳まわりの画素をマスクで切り分け、重ねている。Inner／Base の露出する重なり部分には、その層の直前までの既存の組み上げ画素を用いた。これは生成画像だけを丸ごと差し替えた結果ではなく、既存画像と生成画像の切り出し・合成を含む。

**白目**：内側の白い楕円と縁を画像編集で除去した。上端の薄い青紫から下の白へ移る柔らかい陰を残した。生成画から少し広めに切り出し、元の白目のアルファで切り抜いたため、左右とも外形・部分透明度は元と完全一致している。二重の楕円は目線移動の確認図で解消している。

**瞳**：黒いまつげの切れ端を画像編集で除き、上端を丸く補った。R はy1000以降、L はy990以降の元画素をそのまま残した。瞳孔、内部の模様、下部の光、位置・幅はこの保持部分で変わっていない。上端だけ R が4px、L が3px上へ延びた。上部の編集領域内には生成由来の小さな色差があり、全画素同一ではない。

## 手順と生成回数

白紙からの生成は使用していない。全12回とも既存の層画像を参照した編集。各層1回、Ear_L_Outer と Ear_R_Base のみ2回。4回の上限以内。

- Ear_L_Outer-01 は不要な白い内毛が追加されたため不採用、02を使用。
- Ear_R_Base-01 は耳全体が追加されたため不採用、02を使用。
- 生成原画は `edits/`、入力は `inputs/`、生成原画と入力の比較は `qa/*-raw-compare.png`。
- [生成の記録](generation-provenance.json)、[配置・切り分けの記録](placement.json)。

プログラムで新しい毛・輪郭・グラデーションを描画していない。緑との色差による透明化、元のアルファ／既存の重なりから得たマスクによる切り抜き、既存・生成画素の合成、縦横同率の拡大縮小と移動を使用した。切り抜きマスク内の微小な穴は埋めて、毛に穴が開かないようにした。素材自体の回転やメッシュ変形は行っていない。

## 検証結果と残る確認

- 10層とも2172×2896・RGBA。
- 左右白目のアルファは元と完全一致。
- 左右瞳の保持部分の RGBA は元と完全一致。
- 差し替え層の範囲外は元の正面と完全一致。
- 耳だけを差し替えた正面は、RGBA の最大差が 40/255、差のある画素が 2460、5階調を超える差が 892 画素。完全なピクセル一致とはしていない。
- current の全ファイル変更なし：True。

耳の根元は既存画素と補完画素が接合するため、単体拡大では重なり線や元画像由来の薄い縁が残る箇所がある。正面比較と参考回転図を用意したが、実際のリグで耳を倒したときの継ぎ目・露出量は未確認。採用時には6つの耳層を一緒に確認する必要がある。数値検証だけで実機での完成を保証するものではない。

## 再現

スクリプトは `scripts/live2d/v24/prepare.py`、`build.py`、`verify.py`、`report.py`。順に実行する。生成原画は保存済みなので、通常は build → verify → report で再構築できる。Pillow、NumPy、SciPy を使う。`build.py` は既存の placement.json があれば同じ変換を再利用する。

書き込んだ成果物・スクリプトは v24 の2つの指定ディレクトリ内のみ。画像編集ツールが自動保存する元画像キャッシュからは、原画を `edits/` にコピーして使用した。
