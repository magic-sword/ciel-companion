# ぷんすか・折れ耳の候補

見本は v22/expressions/angry.png。正式採用済みの v34 モデルを基に、口・眉・左右の折れ耳を追加する。

耳のメッシュを細かくするだけでは、立った耳と折れ耳の見える面、毛の重なり、短く見える輪郭の違いを作りにくい。耳は見本の顔全体・輪郭線を含む文脈で生成し、画像編集で左右を分離した。口・眉は生成画像の候補を採用せず、承認済み見本から直接切り出した。目・頬の赤み・顔土台は既存素材を利用する。

眉は前髪の線と重なっているため、切り出しだけでは髪の切れ端が混入した。見本の眉の輪郭をトレースし、色と透過度を整えて清書した。新しい形を画像生成したものではない。

眉と瞼の線の重なりを避けるため、Cubism上の眉メッシュだけを上へ32px（2172×2896キャンバス基準）移動した。左右同量で、横位置・形・角度・素材画像・透過度は変更していない。`integrate-angry.py` にも同じ位置補正を反映した。変更前後の拡大比較は `rig/proofs/angry-v35/brow-position-comparison.png`。

`ParamAngry` で口・眉、`ParamEarFold` で折れ耳を切り替える。元の耳6パーツは折れ耳時に非表示。折れ耳は元の左右の耳デフォーマーに所属させる。耳の大きな折れ方は差分素材で表現し、既存の `ParamEar` は基本0にする。

顔は鼻と顎、耳は左右の先端を基準に共通倍率で配置した。左右を個別に拡縮していない。配置値と原本のハッシュは placement.json に記録する。

原本は edits/、分離前の座標を保ったパーツは parts/、Cubism用の2172×2896画像は layers/。正式素材の入口 assets/ciel/current/ とは区別する。比較・検証結果は assets/ciel/rig/proofs/angry-v35/ に保存する。
