# 頭頂部の素材修正案 v45

マスター `assets/ciel/master/ciel-upper-body-2x.png` から、耳・前髪・アホ毛の間に見える頭頂部を分離した。新しい画像生成は行わず、画像編集で `Hair_Crown` の透明PNGを作成した。

後ろ髪を持ち上げる旧案は、髪の縦線を伸ばし、頭頂部を横長の白い面にしてしまっていた。今回はマスターの上部の毛流れ・青紫の淡い陰影を利用し、素材全体の拡大や縦方向の引き伸ばしは行っていない。

元のアホ毛の根元が素材に残ると二重になるため、その範囲をマスターの隣接した髪の帯でクローン補修した。補修範囲だけは近隣の色を使い、3pxでなじませる。マスターの切り抜きに残っていた黒い穴・汚れは近隣の髪の色で補修し、透明度は清書した輪郭マスクを使う。下側は前髪の下に隠れる範囲でフェザー処理した。

素材は `parts/Hair_Crown.png`、モデル上の配置版は `layers/Hair_Crown.png`。配置はマスターと同倍率、y=-4px。原本と処理の記録は `generation-provenance.json`・`placement.json`。

通常・ジト目・わくわく・半泣きの静止画で素材を確認し、ユーザー承認後に正式CMOへ取り込んだ。[マスターとの素材比較](../../rig/proofs/crown-v45/master-crown-comparison.png)、[全表情の実モデル描画](../../rig/proofs/crown-v45/all-expressions.png)。頭頂部は頭に追従する前髪側のデフォーマにつなぐ。下側の後ろ髪の揺れで頭頂部の付け根は動かさない。現行92層・正式CMO・Unity更新用SDKへ反映済み。Unity本体への適用はまだ行っていない。

再現：`scripts/live2d/prepare-crown.py`。旧案のメッシュ引き伸ばしは併用しない。
