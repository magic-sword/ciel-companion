# 顔の肌色の共通修正 v46（採用済み）

顔土台の肌色を、現行のお腹とマスターの肌色を参考に画像編集で調整した。新規画像生成は行っていない。

代表的な明るい領域のRGB中央値は、顔土台が(254,249,247)、マスターの顔が(250,249,249)、現行のお腹が(249,248,249)。顔土台は赤・黄寄りになっていた。

お腹の色味を基準に、顔の明るさをほぼ保ちながら、RGBを約(-3.37,+0.63,+3.63)補正する。補正は明るく彩度の低い暖色部分に限定し、輪郭線や青紫の陰影は保つ。顔土台だけでなく、左右の上下まぶたの肌色と上下の口元の肌色をそろえた。透明度・サイズ・メッシュは変更しない。頬の赤み、首、お腹の素材も変更しない。

候補の7層は `layers/`、色の測定値と処理の記録は `generation-provenance.json`。[マスター・現状・調整案](../../rig/proofs/skin-v46/master-comparison.png)、[顔とお腹の比較](../../rig/proofs/skin-v46/face-and-body-comparison.png)。通常・嬉しい・照れ・半泣きの静止画で色のなじみを確認した。

ユーザー承認後、7層を既存パーツの差し替えとして正式CMOに反映した。素材数は92層のまま。アトラスを再構築し、[全表情の実モデル描画](../../rig/proofs/skin-v46/all-expressions.png)と検証記録を保存した。現行素材・編集用PSD/XCF・Unity更新用SDKを同じ版にそろえた。Unity本体への適用はまだ行っていない。再現用スクリプトは`scripts/live2d/prepare-skin-tone.py`、取り込みは`integrate-skin-tone.py`。
