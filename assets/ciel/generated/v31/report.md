v30の輪郭付き透明画像をマスクで7パーツに分離した。新しい画像生成は行っていない。
画像編集処理にはPillowを使用。画素の描き足し・塗り直し・色変更はしていない。

## 分離素材

`parts/`は元の970×970の座標を保ったPNG。`layers/`は2172×2896のモデル用座標に置いたPNG。

| 名前 | 内容 |
| --- | --- |
| Eye_R_Happy / Eye_L_Happy | 左右の笑い目とまぶた線 |
| Cheek_R_Blush_Happy / Cheek_L_Blush_Happy | 左右の頬の赤み |
| Mouth_Happy | 開いた笑い口 |
| Nose | 鼻の点 |
| Face_Contour | 頬・顎の輪郭線 |

マスクで画素を排他的に割り当て、元のアルファを保持した。
分離した7枚を元の座標で重ね直したとき、透明以外のRGBA画素と全アルファが
v30の元画像と完全に一致することを検証した。
元画像にある微細な透明境界・低アルファの残りも保存しており、線の形の修正はしていない。

## 配置と合成

元の輪郭のy520にある左右端x192・788を、現在のFace_Skinのy1200の左右端x807・1398へ合わせた。
頬の輪郭幅を基準とする単一の倍率（591/596）と移動を、7枚すべてに共通で適用。
目だけ・口だけの大きさや位置は変更していない。

現行layers.jsonの重なり順を使い、元の目の各層・口・鼻を非表示にして新素材を合成。
赤みは今回抽出した素材そのもののアルファで表示し、以前の0.45の表示量は適用していない。
髪は目より上へ重ね、髪に隠れる目尻はそのまま隠した。
見本にも同じ倍率・移動を適用した比較図を作った。

輪郭線は配置ガイドとして使用。通常の完成比較では既存の顔の土台を使い、
抽出した輪郭線を重ねて二重線にすることは避けた。
輪郭を重ねた別の診断図では、既存の顎との約10pxのずれと頬の差が見える。
顔の土台の輪郭自体を差し替えた完成品ではない。

## 見た目と限界

目尻は横髪の近くに収まり、輪郭を共通の配置基準にできた。
一方、見本との目・口の形、頬の赤みの濃さの差は残る。
v30の生成を伴う抽出に由来する差で、今回の分離で描き直したものではない。
現在の顔の土台と髪は見本と同じ形ではなく、共通の倍率だけで全部の輪郭は一致しない。

これは差し替えた状態を確認する静止合成画像。Cubism・Unityの素材は未変更。
実際のメッシュ・頭の角度・口パク・表情遷移の確認には取り込み後の検証が必要。
[verification.json](verification.json)に再合成一致と現行素材のハッシュ一致を記録。
再現：`scripts/live2d/v31/build.py`、倍率・座標：[placement.json](placement.json)。
