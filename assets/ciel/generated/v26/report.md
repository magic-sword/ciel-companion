# v26 嬉しい：笑い目と上がった頬の修正案

ユーザーの「v25 は改善したが見本に比べて物足りない」という指摘を受け、目と頬のつながりを修正した。

- [見本・v25・v26 の顔の比較](proofs/happy-face-comparison.png)
- [v25・v26 の全体の比較](proofs/happy-front-comparison.png)
- [今回の素材合成、全キャンバス](proofs/happy-assembled.png)

今回の図は素材合成。Cubism・Unity のモデルはまだ変更していない。

## 変更

笑い目に中央の厚みと丸みを戻し、先端は細いままにした。小さな白い光を残し、薄いまぶたの線を添えた。
頬の赤みは前の案より上、目の直下へ寄せ、笑い目と一緒に頬が上がって見えるようにした。
赤みは別の透明層で、比較図では表示量0.55。全表示で強くなりすぎたため、表示量で調整した。
口は v25 の `Mouth_Happy` の画素をそのまま使用した。

## 素材

全て2172×2896のRGBA PNG。左右名は既存モデルに合わせ、Rは画面左、Lは画面右。

| 層 | 内容 |
| --- | --- |
| [Eye_R_Happy.png](layers/Eye_R_Happy.png) | 笑い目と薄いまぶたの線、画面左 |
| [Eye_L_Happy.png](layers/Eye_L_Happy.png) | 同上、画面右 |
| [Cheek_Blush_Happy.png](layers/Cheek_Blush_Happy.png) | 嬉しい専用の高い位置の赤み、左右一枚 |
| [Mouth_Happy.png](layers/Mouth_Happy.png) | v25の笑い口を変更せず同梱 |

目にも口にも肌パッチは含まない。現在の顔の肌・髪・眉・鼻・輪郭・首輪・耳をそのまま重ねている。
嬉しい専用の赤みなので、照れなどに使う既存 `Cheek_Blush` は置き換えていない。

## 工程と検証

1. v25の組み上げた顔の1050正方形を元画像とし、承認済みv22の顔を参照して目と頬だけ画像編集した。
2. 編集した顔から、笑い目・まぶたの線だけを画像編集で透明背景へ抽出した。
3. 頬の赤みだけを画像編集で黒背景へ抽出し、色に基づくアルファで透明化した。
4. 矩形による切り分け・アルファ範囲の切り詰め・縦横同率の拡大縮小・移動のみで配置した。線や肌の描き足し、非等方変形はしていない。
5. 既存の目と口を非表示にし、修正素材を既存の層順に重ねて、拡大と全体で確認した。

生成は顔編集1回、目抽出1回、頬抽出1回。入力・生成原画・抽出原画を保存した。
依頼文は [generation-provenance.json](generation-provenance.json)、配置は [placement.json](placement.json)。
`scripts/live2d/v26/build.py` で保存済み原画から再構築できる。

[verification.json](verification.json)で、キャンバス・RGBA・素材が空でないこと、口がv25と同じこと、currentが作業前と同じことを確認した。
見本と画素単位で一致する素材ではなく、表情の印象は比較図で判断する。ユーザーの採用承認はまだ受けていない。

取り込み時は、通常の目を非表示にする構成を維持し、笑い目・口・嬉しい用の赤みをそれぞれ制御する。
目の絵の範囲が変わったので、メッシュとアトラスも更新する。反映後に頭の角度、表情フェード、口パクを確認する。
