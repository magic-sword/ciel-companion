# v32 にこにこ：専用の切り替えと既存動作の維持

ユーザーから素材の再生成も許可されたため、変形だけに限定せず、切り替えと動作の維持を優先した。
`ParamRelaxed`を0から1にすると、口・頬とまぶたの形がまとめてにこにこへ切り替わる。

## 素材と構成

承認見本を編集入力とし、目・口・赤み・鼻・輪郭線を1枚の透明画像に抽出した。
画像生成は1回。生成原画は`edits/relaxed-details-with-contour-01.png`。
依頼文と由来は[generation-provenance.json](generation-provenance.json)。
見本と画素が一致する切り抜きではなく、目・赤み・線に描き直しの差がある。

画像編集のマスクで、閉じた微笑みの線と左右の赤みだけを分離し、
鼻と顎・頬の輪郭を基準に共通の倍率と移動を適用した。
生成した目は目標の資料として残し、動作中の目の画像は交換していない。
分離は`v32/prepare.py`で再現できる。色の描き足しはしていない。
赤みはメッシュの不透明度0.5で表示する。

| 部位 | 実装 |
| --- | --- |
| 目 | 既存の白目・まぶた・まつ毛に専用変形キーを追加。上まぶたを少し下げ、下まぶたを持ち上げる |
| 瞳・ハイライト | 既存の素材と目線・クリッピングを維持 |
| 閉じた口 | 新しい`Mouth_Relaxed`を表示。元の閉口線2層を隠す |
| 話している口 | 新しい閉口線を目立たなくし、既存の開口素材を使う。開口1では新しい線が完全に消える |
| 頬 | 新しい`Cheek_Relaxed`を表示。元の赤みとの二重表示を避ける |
| 顔土台・横髪・耳 | 画像と既存動作を維持 |

まぶたの変化は目の開閉値に比例させ、完全閉眼では追加の変位を0にする。
通常顔と前回の嬉しい顔のキーは、専用パラメーター0で元の位置・不透明度に戻る。

## 切り替え

`ParamRelaxed=1`でにこにこ、0で通常の形。
前回の嬉しい顔が有効な場合は、その`ParamHappy`と左右の`ParamEye*Smile`を0へ戻す。
`assets/ciel/rig/expressions/`に通常・嬉しい・にこにこの3つのexp3.jsonを用意した。
各ファイルは4つの表情用パラメーターを明示的に切り替え、目の開閉・目線・口の開閉を固定しない。
この3表情の切り替え用であり、他の表情は従来の設定を引き続き使う。

## 確認と適用範囲

Cubismでモデルを開き、アトラスを再配置・保存・moc3書き出しした。
Coreで通常顔・前回の嬉しい顔の全既存メッシュの頂点と不透明度が以前と一致することを検証。
閉眼線の表示、開口時の新しい閉口線の非表示、通常復帰、ID重複なしも確認した。
表情の中間値・目の開閉・目線・顔の角度の81組み合わせで有限の頂点を検証した。
検証は`check-relaxed.py`、取り込みは`integrate-relaxed.py`。

今回の比較では閉じた微笑みの線が明瞭になった。一方、まつ毛の太さ・目尻の形は
既存素材由来で見本との差が残る。見た目は比較図で判断し、完全一致とは扱わない。
正式なCubismモデルと現行素材64層へ反映した。Unityへの取り込み・会話からの切り替えは未更新。
作業前のモデルと素材は`.local/relaxed-integration/`に退避した。
