# しょんぼりの候補

基準は v22/expressions/sad.png。v35のぷんすか候補を基に、しょんぼり専用の眉・口を追加した。新しい画像生成は行わず、見本の口を画像編集で抽出し、眉は見本の輪郭をトレースして重なった髪の線を除いた。鼻・顎を基準に同じ倍率で配置する。

`ParamSad` で眉・口と伏せ目を切り替える。初案の中央40pxの下げ方では上の白いハイライトが隠れたため、上瞼の中央は28px下げ、目尻側を9px下げ・目頭側を9px上げる形に修正した。下瞼の中央の持ち上げは3pxに弱め、端の上下差を付ける。閉眼キーと笑い目にはこの変形を重ねない。発話時は既存の開口パーツを使う。

虹彩とハイライトは素材を再生成せず、同じ変換で位置を合わせた。縦方向を0.9倍（基準y=1070）にして下へ28px移動する。横方向は維持。目線のキーに同じ補正を適用し、通常や他の表情には重ねない。前の候補との比較は `rig/proofs/sad-v36/eye-refinement-comparison.png`。

耳は v35 の折れ耳を `ParamEarFold=1` で共用し、`ParamEar=0` を基本とする。頬は共通素材の `ParamCheek=0.2`。新しい耳・涙・頬・顔土台は追加しない。

素材は parts/ と layers/、配置・原本ハッシュは placement.json。比較は `assets/ciel/rig/proofs/sad-v36/`、モデルと書き出しは `assets/ciel/rig/drafts/sad/`。正式採用済みv34と、ぷんすか候補v35は保持する。

虹彩の上側に白い帯が出ないよう、虹彩の上端だけを最大38px延長し、瞼の裏まで覆う。瞳孔付近とハイライトにはこの延長を適用しない。

上瞼の山なりがまだ強かったため、見本と前回モデルのまつげ上端を同じ座標で測り、左右別々の二次曲線で追加補正した。虹彩・ハイライト・下瞼は前回の設定を維持する。最新の変更前後は `rig/proofs/sad-v36/lid-shape-comparison.png`。

正式採用済み。現在の編集対象は `assets/ciel/rig/ciel.cmo3`、素材は `assets/ciel/current/`、Unity更新は `assets/ciel/runtime/`。旧候補はローカルの採用時アーカイブへ退避した。
