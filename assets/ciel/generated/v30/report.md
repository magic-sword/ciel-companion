# v30 輪郭線を含む表情素材の一体抽出

ユーザー依頼に合わせ、承認済み「嬉しい」の見本から、笑い目・口・赤みと顔の輪郭線を一度に抽出した。
既存のv27素材やv28の赤みを再利用せず、見本を直接画像編集ツールへ渡した。

- [一体の透明PNG](face-details-with-contour.png)：970×970。目・口・赤み・鼻・輪郭線を同じキャンバスに保持。

- [目・赤み・口・輪郭の拡大比較](proofs/details-comparison.png)
- [未加工の抽出原画](edits/face-details-with-contour-02.png)：1254×1254。

## 方法と結果

髪・肌の塗り・首・首輪を除き、表情の線と色、頬から顎までの輪郭線を透明背景に取り出すよう依頼した。
1回目には肌色の残りと形の差が見られたため、原見本から再試行した。2回目を今回の比較用に選択。
輪郭の一部は元の髪で隠れているため、画像ツールが補完した線を含む。

抽出原画の鼻・顎を基準に、全パーツへ共通の縦横同率の縮小・移動を適用し、
見本と同じ970×970キャンバスに置いた。目だけ・口だけの倍率変更や位置修正はしていない。
輪郭を含む一体画像のまま残し、後から分離できるようにした。
輪郭があるため、目・口の高さや大きさを顎・頬に対して比較しやすい。

ただし画像編集ツールの抽出は、元画像から画素をそのまま切り抜く処理ではない。
目のまつ毛の弧・先端・まぶた線、口の大きさ、頬の赤みの広がり、輪郭線の太さに差が残る。
赤みには肌色に近い色味が残り、元画像の赤い顔料だけを厳密に分離できたとは言えない。
鼻・顎をそろえた後も他の特徴に差があるため、輪郭を含めれば生成時のバランスが
完全に保たれるという結論にはしていない。比較・配置の基準として使えることを確認した段階。
