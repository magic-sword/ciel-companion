# 半泣きの候補（v40）

**正式採用済み**。顔の4層はv40、折れ耳はv42を使用する。[最新の実モデル比較](../../rig/proofs/teary-v42/reference-comparison.png)。以下は初回候補の作成記録。CMO・SDKの旧候補は `.local/teary-adoption/adopted-draft/` へ退避した。

見本はv22/expressions/teary.png。顔全体を鼻・顎で位置合わせし、波打つ口と、下まぶたにたまる涙を左右別に画像編集で取り出した。眉は髪の線が混ざらないよう見本の輪郭を清書。新規の画像生成は行っていない。

目元は見本の上まつげの輪郭を測って合わせ、虹彩とハイライトは正面の目線を保つ。下まぶたは肌色の覆いと旧線を非表示にし、既存のにこにこ用の線を白目の境界へ合わせる。頬の赤みと折れ耳は既存素材を利用する。

左右の涙は白目と同じ親デフォーマに付け、瞳の目線移動には追従しない。顔の向きには追従し、半開きでは薄く、閉眼では非表示にする。旧Tear_L/Rは半泣き中に非表示にして重なりを避ける。発話の口は既存パーツを使う。

採用済み79層モデルへ眉・口・左右の涙の4層を追加した83層の候補。モデル・SDK書き出しは `assets/ciel/rig/drafts/teary/`、比較と検証は `assets/ciel/rig/proofs/teary-v40/`。正式モデルとUnityへは未適用。
