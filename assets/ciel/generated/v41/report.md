# サモエドらしい折れ耳の候補（v41）

**再検討により不採用**。大きさの変化が小さいとの指摘を受け、[v42](../v42/report.md)へ進んだ。正式モデルへは組み込んでいない。

原本・分離素材は `.local/archive/codex-generated/v41/` へ退避。ここには経緯と配置情報のみ残す。

半泣きv40の顔全体を入力にし、耳だけを文脈付きの画像編集で描き直した。最初の案は耳が長く垂れすぎたため不採用とし、短い三角形を保って先端を丸め、付け根と内側の毛の量感を増やした2回目を選んだ。元画像は `edits/teary-samoyed-ears-context.png`。

左右の耳は生成後にマスクによる画像編集で分離。形の描き足し・個別の拡大縮小は行っていない。両耳へ同じ倍率と移動を適用し、2172×2896のモデル座標に置いた。生成画像の顔・髪は素材として採用しない。

確認図は、半泣き候補のCubism Core描画で折れ耳の画像面だけを差し替えた**静止合成**。実モデルの髪を元の描画順で重ね、目・口・涙・頬を変更せずに比較した。ぷんすか・しょんぼり・困り・照れでも同じ配置を確認する。これはCubismモデルへの取り込みやSDK書き出し後の動作確認ではない。
