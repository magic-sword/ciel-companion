# 依頼：ほっぺを指でつついたときの、くぼみの影の素材（v64）

## 背景
アプリでシエルのほっぺを指で「ツン」とつついたときに、ぷにっとした感じを出したい。
ほっぺ全体の輪郭を変形させる案は、ユーザーから「頬骨まで変形しているように見える」と言われた。ユーザーの提案は次のとおり：

> ツンって押した時の、その柔らかいものをちょんと押した時のくぼみの影みたいのがちょっとできる。画像で言うとエクボ的な感じ

そこで、押した所に出る小さな「くぼみの影」（えくぼのような、柔らかい凹みの影と、ふちの小さな光）を、左右のほっぺの素材として作る。
アプリでは、この素材を押した量に合わせて濃くしたり薄くしたりする（輪郭は動かさない）。

頼み方の決まり：`docs/ciel-codex-request-guide-ja.md`（白紙から描かない。承認済みの絵の編集として描き、色の差から切り出す）。

## 元にする絵
- `assets/ciel/generated/v64/inputs/neutral-full.png`：今のモデルの正面（キャンバス 2172×2896。背景は #FF00FF）。
- `assets/ciel/generated/v64/inputs/neutral-face-crop.png`：上の絵の顔の部分（キャンバスの x 700〜1520、y 820〜1500）。編集はこちらを拡大して行ってよい。戻すときは逆の変換で、元の位置へ置く。
- `assets/ciel/generated/v64/inputs/dimple-positions.png`：くぼみを入れる位置（赤い楕円。クロップの中の位置）。キャンバスでは、画面の右（モデルの左）が (1312, 1232)、画面の左（モデルの右）が (908, 1232) あたり。

## 段階
1. 顔のクロップを元に、左右のほっぺの赤い楕円の位置へ、指でちょんと押したような小さなくぼみの影を描き足す**編集**をする。
   - 描くもの：直径 50〜60 px（キャンバスの画素）くらいの、やわらかい凹みの影。影は凹みの上側・外側にうっすら、ふちの下側にごく細い明るい光。指は描かない。
   - 色：白磁の肌に合う、薄い青紫〜灰色がかった影（今の絵の、あごや首の影の色に合わせる）。赤みは足さない。
   - 濃さ：はっきり分かるが、強すぎない。アニメの塗りの、やわらかいぼかし。線（輪郭線）は描かない。
   - **変えてはいけないこと**：ほっぺの輪郭・あごの線、目・まぶた・眉・鼻・口、横髪、首、肌の色、画面のほかの所すべて。
   - 確かめ方：元と編集後を重ね、くぼみの影の範囲（楕円のまわり）以外に差がないこと。生成し直しは 4 回まで。
   - 濃さ・形の違う 2 案を作る（A：丸いくぼみ。B：三日月形の影が目立つくぼみ）。
2. 切り出し：元の絵と編集後の絵の色の差から、くぼみの影だけの透明 PNG を、左右別々に作る（描き足し・塗り・変形はしない。差から決めるアルファはよい）。
   - 出来上がった層を元の絵の上に普通に重ねると、編集後の絵と同じになること。
   - ファイル名：`Cheek_Dimple_L_A.png`・`Cheek_Dimple_R_A.png`・`Cheek_Dimple_L_B.png`・`Cheek_Dimple_R_B.png`（L は画面の右、R は画面の左）。
   - 大きさ：キャンバスと同じ 2172×2896 の透明 PNG。くぼみの位置は、元の位置のまま。
3. 確認図：
   - 案ごとに、元・編集後・差の強調（くぼみのまわりを 3 倍に拡大）を並べた図。
   - 層を暗い背景に置いた図。
   - 層を元の絵に重ねて、もう一度描いた図（編集後と一致するか）。
