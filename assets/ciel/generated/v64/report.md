# v64：ほっぺをつついたときのくぼみの影

**採用：A（丸い浅いくぼみ）**。2026-10-17 に正式モデルへ取り込んだ（現行素材 `../../current/layers/Cheek_Dimple_{L,R}.png`）。押した量 0→1 で不透明度 0→0.3 にして使う。取り込みとリグは [cheek-v64 の確認図と検証](../../rig/proofs/cheek-v64/)。
B（三日月形の影）と、引っ張ったときの影の候補（依頼 req-51、とがった引き伸ばしで不採用）は採用せず、素材を削除した。比較の記録として [元・A・B の顔比較](previews/variants-overview.png) だけを残す。依頼全文は [request.md](request.md)。

## 納品素材

すべて 2172 × 2896、8 bit のストレートアルファ RGBA PNG。元キャンバスの座標を保ち、透明部分の RGB は 0。L は画面の右／モデルの左、R は画面の左／モデルの右：[Cheek_Dimple_L_A.png](Cheek_Dimple_L_A.png)・[Cheek_Dimple_R_A.png](Cheek_Dimple_R_A.png)。

## 作り方

`docs/ciel-codex-request-guide-ja.md` に従い、承認済みの `inputs/neutral-face-crop.png` を画像編集の入力にした。`inputs/dimple-positions.png` は位置の参考にだけ使った。部品を白紙から生成していない。

編集時には、直径約 55 px、指を描かないこと、上側・外側の青紫〜灰色の影、下縁の細い光、赤みや輪郭線を足さないことを指定。目・眉・鼻・口・髪・頬や顎の線・首・全体の肌色を変えないよう指定した。

生成は計 3 回（A 初回、B、A 修正）。A 初回は影が下側に寄っていたため不採用とし、上側の柔らかい影を指定して修正した。採用した生成原本は [A](edits/A-generated-selected.png)。

### 元座標への復帰と変更範囲の限定

提供クロップは 820 × 680 で、元画像の `[700, 820, 1520, 1500)` と画素単位で一致した。画像編集ツールの出力は 1377 × 1142 だったため、両軸に同じ倍率 `820 / 1377 = 0.5954974582` を適用して復帰した。画素中心を合わせる Bicubic の逆変換を 1 回だけ使い、820 × 680 の範囲を取り出した。縦横別の倍率、局所変形、部品の個別移動は行っていない。

生成原本は頬以外も厳密には元と一致していなかった。このため生成画像を顔全体へ貼らず、くぼみ周辺だけをマスクで採用した。それ以外は提供画像をそのまま使用した。

- 指定中心：R `(908, 1232)`、L `(1312, 1232)`。
- 生成されたくぼみを囲む選択中心：R `(912, 1236)`、L `(1304, 1236)`。くぼみ自体は移動していない。生成による数 px 程度の位置差が残る。
- 選択範囲は各中心の半径 35 px 未満。外縁 6 px は選択マスクをフェザーし、隣の横髪を含まないようにした。
- 微小な再生成差を採用しないため、各画素の RGB 最大絶対差 `d` に対して `clip((d − 3) / 4, 0, 1)` をマスクのアルファに使用した。
- これは生成画素の選択・マスク・通常合成であり、コードで影を描いたり、色を塗り直したりしていない。

採用マスクは `edits/A-difference-mask.png`、編集後の顔クロップは [A](edits/A-edited-face.png)（全身の編集後画像は、元の絵へ納品素材を通常合成すれば再現できる）。以下の「一致」は、生成原本全体ではなく、この局所マスクを適用した編集後画像との一致を指す。

### 色差から透明素材を切り出す方法

元画像の RGB を `S`、納品用の編集後 RGB を `T` として、通常合成の式 `T = αF + (1 − α)S` を逆に解いた。各画素で `F` が 0〜255 に収まる最小の 8 bit アルファを求め、そのアルファから前景 RGB `F` を計算した。元と同じ画素は完全透明。影の色を別の色へ置換する処理や、影の描き足しは行っていない。

左右を分けて元キャンバスに置き、保存した PNG を読み直して通常合成した。左右の合成後画像を編集後画像と比較し、RGB 全チャンネルの差が 0 であることを確認した。

## 検証結果

| 検査 | A | B |
| --- | ---: | ---: |
| 元から変わった画素数 | 5,633 | 2,910 |
| くぼみ選択範囲外の変更画素数 | 0 | 0 |
| 選択範囲内の保護対象（元の RGB 最小値が 245 未満）の変更 | 0 | 0 |
| 保存済み左右 PNG の再合成と編集後の不一致画素数 | 0 | 0 |
| 再合成の RGB 最大誤差 | 0 / 255 | 0 / 255 |

目・まぶた・眉・鼻・口・横髪・首・頬や顎の輪郭線は選択範囲に入らず、元画像と同じ画素を保持している。全身キャンバスでも選択範囲外の変更が 0 であることを確認した。全体の肌色変更や頬全体の変形は行っていない。

見える影の幅（元との差が 8 / 255 以上の部分）は A が約 55〜59 px、B が約 40〜42 px。B は薄い縁と光まで含めると約 61 px 幅。A は影の面が広く、B は細い三日月形の影が強い。完全不透明度での顔比較を目視し、2 案の違いと、輪郭・顔パーツに差がないことを確認した。

入力・採用した生成原本・納品 4 枚の SHA-256、正確な非透明範囲、生成原本の差の数値は [verification.json](verification.json)。再作成用スクリプトは [build_deliverables.py](build_deliverables.py)。
