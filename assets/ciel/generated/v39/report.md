# 照れ顔：目尻と赤みの調整（v39）

v38の顔を基に、照れのときだけ上まつげの外側の下向きの尾を短くした。変形は外側へ滑らかに強くなり、目の中央のアーチ・虹彩・白目・下まぶたを変更しない。半開きでは調整量を半分にし、閉眼と笑い目のキーを維持する。

赤みはv38の見本由来の透明素材を画像編集で調整。面の赤みをぼかして弱め、細かな斜線の差分を残した。色を淡い赤へ寄せ、素材の外周は滑らかに透明になるようにした。元の位置とモデルの鼻は保つ。新しい画像生成は行っていない。

眉・口はv38を共用し、差し替える画像は `layers/Cheek_Embarrassed.png` の1枚だけ。モデルは79層のまま。正式モデルは `assets/ciel/rig/ciel.cmo3`、SDK書き出しは `assets/ciel/runtime/`、比較は `assets/ciel/rig/proofs/embarrassed-v39/`。正式モデルと現行素材へ採用済み。Unity更新パッケージは検証済みで、Unityのモデル自体は未適用。候補の重複は `.local/embarrassed-adoption/adopted-draft/` へ退避した。
