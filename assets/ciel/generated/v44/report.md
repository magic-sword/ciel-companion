# ジト目の調整候補（v44）

上まぶたの補助線も見本から分離して左右の上まつげ素材に含めた。旧補助線はジト目中に非表示にして、変形で生じた波打ちと二重表示を避ける。虹彩・瞳の切れ端が上まつげに混ざらないよう、暗いまつげと青い虹彩の色を区別してマスクを整えた。

見本v22/expressions/jitome.pngの顔全体を鼻・顎で位置合わせし、ほぼ水平な上まつげと小さな口を画像編集で分離した。眉は見本の平たい輪郭を清書し、髪の線を混ぜない。新規の画像生成は行っていない。

`ParamJitome`で専用の左右上まつげ・眉・口を切り替える。通常の虹彩と目線のデフォーマは維持し、目元の白目マスクを専用形状へ合わせる。虹彩とハイライトを少し下へ置き、下まぶたの肌色の覆いと旧線を非表示にし、既存の下まぶた線を白目の境界へ合わせる。

上まつげは左右それぞれのまばたきに連動し、閉眼では既存の閉じ目へ切り替える。発話の口も既存パーツを利用する。耳は既存の立ち耳をやや横へ傾け、頬の赤みは共通素材を淡く使う。

採用済み87層に4層を追加した91層で候補を検証した。その後、共通頭頂部v45を加えた92層の正式モデルへ採用した。現行素材は`../../current/`、正式CMOは`../../rig/ciel.cmo3`、最新の実モデル検証は [crown-v45](../../rig/proofs/crown-v45/README.md)。旧候補CMO・SDKは`.local/crown-adoption/adopted-jitome-draft/`へ退避した。Unity本体への適用はまだ行っていない。

最終SDKで既存11姿勢の頂点・不透明度が維持されることを確認した。左右独立のまばたき、目線追従、発話時の口の切り替え、および表情・開眼・目線・顔の向きの81組み合わせの検証が通った。
