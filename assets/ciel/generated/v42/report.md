# 通常時の耳の量感を残す折れ耳（v42）

**正式採用済み**。既存の折れ耳2層を差し替え、半泣きv40とともに正式モデル・Unity更新パッケージへ反映した。[SDK書き出し後の実モデル比較](../../rig/proofs/teary-v42/reference-comparison.png)。以下は採用前の素材比較記録。Unity本体への適用は未実施。

v41は先端の丸みや毛を調整したものの、モデルに重ねたときの大きさがほとんど変わらなかった。ユーザーから再検討の指示を受け、v41の採用・モデル取り込みは中止した。

今回は半泣きv40の顔に加え、通常時の立ち耳と承認済みの半泣き見本を入力にした。通常時の耳の量感を残しながら、見本のように耳先を外側・下側へ向ける。耳を細長くぶら下げず、広い三角形の面と内側の白い毛を残す。

顔全体の中で耳を生成し、左右をマスクによる画像編集で分離した。顔・髪は生成画像から採用せず、実モデルの描画をそのまま使う。共通倍率と移動で左右の耳を置き、既存の髪を元の描画順で重ねた。
