# 照れ顔：初回調整の記録（v38）

現在の採用版はv39。口と眉はこの版を共用し、赤みと目尻はv39で修正した。最新のモデル・素材は `assets/ciel/rig/ciel.cmo3` と `assets/ciel/current/` を参照。以下は初回候補を作った時点の記録。

見本はv22/expressions/embarrassed.png。鼻・顎を基準に顔全体を同じ倍率で配置し、口と頬から鼻にかけての赤みを画像編集で分離した。赤みは見本の斜線・濃淡を保って透明化し、見本の鼻点は除去した。眉は髪の線が混ざらないよう見本の輪郭を清書。新規の画像生成は行っていない。

`ParamEmbarrassed=1`で目・眉・口・赤みを切り替え、`ParamEarFold=1`で既存の折れ耳を共用する。虹彩とハイライトは左右別に横幅を調整して一緒に右へ寄せ、目線をそらす。上まぶたは見本から測った輪郭へ合わせる。下まぶたは肌色の覆いと旧線を使わず、既存のにこにこ用の線を白目の境界へ合わせた。

採用済み76層モデルに眉・口・赤みの3層を追加した79層の候補。モデル・SDK書き出しは `assets/ciel/rig/drafts/embarrassed/`、比較と検証は `assets/ciel/rig/proofs/embarrassed-v38/`。正式モデルとUnityへは未適用。
