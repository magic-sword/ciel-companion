# 困り顔：虹彩の下端が浮いて見える原因の確認

[見本・現状・下まぶた非表示の比較](lower-eye-diagnosis.png)。非表示の画像は原因を確認するための描画であり、採用案ではない。

Cubism Core の実際の頂点・テクスチャ・クリッピングで、虹彩、白目、下まぶたの肌色、下まぶたの線を分けて確認した。正面・開眼・目線中央では、虹彩中央付近に幅のある白い隙間はない。各眼の中心±40 pxを10 px刻みで測った不透明度0.9の境界では、肌色パーツまでの間隔はほぼ0 px、例外は右眼の1点で1.5 pxだった。この値は見え方全体や半透明の縁を評価するものではない。

肌色パーツを非表示にすると虹彩の下側が現れる。現状は肌色パーツで虹彩下端がやや平坦に隠れ、短い下まぶたの線と連続しにくい。虹彩下部の明るい水色・白い反射も境界を弱く見せている。見本では虹彩下端の丸み・濃い縁・下まぶたの線のつながりが読み取りやすい。主に下まぶたとの重なり方の問題と判断するが、虹彩の配色も見え方に寄与する。

下まぶた中央を6 px上げる、8 px下げる、虹彩下側を8 px伸ばす試描画を実施した。単純な移動・拡大だけでは境界の平坦さや線とのつながりは改善しきれず、下げた場合は線が離れて見える部分もあった。次に直すなら、困り顔のときだけ肌色パーツの覆い方と下まぶたの線を一緒に整え、虹彩下端の丸みを少し残す。まず既存パーツの形・位置の調整で試せるため、素材の再生成を必須とはしない。

この確認では候補のCMO3・MOC3・素材画像を変更していない。他の採用済み表情への影響もない。
