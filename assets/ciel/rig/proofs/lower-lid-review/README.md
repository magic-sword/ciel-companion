# 下まぶたの見直し

困り顔の下まぶたを調整する前の76層モデルを使い、通常・嬉しい・にこにこ・驚き・ぷんすか・しょんぼり・困りを比較した。

- [開眼：現状／下まぶたの肌色パーツを非表示](all-open-eyes.png)
- [半開き：同じ比較](all-half-open-eyes.png)
- 閉眼時の各パーツの透過度は [closed-eye-audit.json](closed-eye-audit.json)。閉眼では肌色の下まぶたと旧下まぶた線は全表情で非表示。嬉しい以外は白目・虹彩の透過度が1のままでも、変形・上まぶたの覆い・閉眼の絵で見えなくなるため、透過度だけで表示の有無を判断しない。

## 必要性

虹彩は白目の形で切り抜かれている。白目そのものにもまばたき・表情の形があり、肌色パーツを一律に必要とする構成ではない。肌色パーツは、白目・虹彩をさらに覆って目の下端を整える補助層。白目の形で目的の下端ができている場合は重複する。下まぶたの線は、白目と肌の境界を読み取りやすくする別の役割がある。

| 表情 | 確認結果 | 判断 |
| --- | --- | --- |
| 通常 | 非表示にしても開眼・半開きの差は小さい。虹彩下端の丸みは保たれている | 現状維持。直ちに削除する理由はない |
| 嬉しい | 笑い目用の絵を使い、肌色パーツ・旧下まぶた線は非表示 | 既存の切り替えで適切 |
| にこにこ | 肌色パーツと旧線を非表示にし、白目の境界に合わせた専用の線を使用 | 既存方式を維持 |
| 驚き | 肌色パーツを外した差は小さい。旧線が境界より少し下に見える箇所は残る | 破綻は見られず維持。今後の微調整候補は線の位置 |
| ぷんすか | 通常の目を共用し、下端の覆い方による差は小さい | 現状維持 |
| しょんぼり | 肌色パーツが虹彩の下側を覆い、下端を平坦・不均一に見せている | 同じ方式で見直す余地あり。今回の検討では採用済みモデルを変更していない |
| 困り | 肌色パーツによる覆いと旧線のつながりが弱い | 今回、肌色パーツと旧線を非表示にし、既存の専用線を白目境界へ合わせた |

## 困り顔の調整

新しい素材は生成・追加していない。`ParamTroubled=1` のときだけ、`Eye_L/R_LidSkin_Lower` と `Eye_L/R_LashLower` を非表示にする。既存の `Eye_L/R_RelaxedLowerLine` を共用し、開眼・半開きそれぞれの白目の下端を実際のSDK描画から測り、線の中心をその境界に合わせる。閉眼・笑い目では線を非表示にする。

[調整前後](../troubled-v37-lower-lid/before-after.png)、[まばたき・発話](../troubled-v37-lower-lid/blink-and-mouth.png)。既存7ポーズのメッシュ位置・透過度は一致し、困り顔の目線・まばたき・顔の向きの81組み合わせを検証した。左右の開眼・半開きで、線の中心と白目の下端の平均距離は0.74～0.82キャンバスpx。線の端や太さによる最大距離は1.78～2.68px。

当検討では候補だけを変更し、採用済みの他の表情を維持した。その後ユーザー承認により、困り顔の下まぶた調整後を `assets/ciel/rig/ciel.cmo3` へ正式採用。現行素材76層とUnity更新パッケージも整理済み。Unityのモデル自体は未適用。肌色パーツの一括削除は行わず、必要に応じて表情ごとに制御する。
