# 半泣きは正式モデルへ採用済み

編集対象は [../../ciel.cmo3](../../ciel.cmo3)、最新素材は [../../../current/layers.json](../../../current/layers.json)。半泣きv40と大きめのサモエド折れ耳v42を採用した83層のモデル。

`ParamTeary=1`・`ParamEarFold=1`・`ParamCheek=0.25`で表示し、他の表情専用キーと旧涙・耳・笑い目の値は0に戻す。まばたき・目線・口パクは固定しない。

[正式モデルの見本比較](../../proofs/teary-v42/reference-comparison.png)、[まばたき・発話](../../proofs/teary-v42/blink-and-mouth.png)、[顔の向き](../../proofs/teary-v42/head-angles.png)。

旧候補CMO・SDKは `.local/teary-adoption/adopted-draft/` へ退避。Unity更新一式は [../../../runtime/README.md](../../../runtime/README.md)。Unityのモデル自体はまだ更新していない。
