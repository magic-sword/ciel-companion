# わくわくは正式モデルへ採用済み

編集対象は [../../ciel.cmo3](../../ciel.cmo3)、現行素材は [../../../current/layers.json](../../../current/layers.json)。見本から分離した笑い口・赤み・左右のキラキラ入り虹彩を採用した87層のモデル。

`ParamExcited=1`・`ParamEar=1`で表示。他の専用表情キーと旧キラキラ・赤み・折れ耳・笑い目は0に戻し、目線・まばたき・口パクを固定しない。

[見本との比較](../../proofs/excited-v43/reference-comparison.png)と[検証記録](../../proofs/excited-v43/README.md)。旧候補CMO・SDKは `.local/excited-adoption/adopted-draft/` へ退避した。

Unity更新パッケージは [../../../runtime/README.md](../../../runtime/README.md)。Unityのモデル本体にはまだ適用していない。
