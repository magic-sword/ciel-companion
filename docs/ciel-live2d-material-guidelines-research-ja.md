# 立体感のある Live2D のための素材の切り分け方（Webリサーチ、2026-10-10）

素材レビューの物差しにするための調査まとめ。**【公式】**は Live2D 公式ドキュメントで確認できたこと、**【推奨】**は検索結果や一般的な制作知識からの補足（一次資料では未確認）。

## 1. 原則（公式）
- 動かす部位ごとに分ける。分けるのは「良い動きに必要な最小限」でよいが、細かく分けるほどモデルの質は上がる。
- **動かしたときに見える部分は、あらかじめ描き足しておく。** 描き足しがないと、動いたときにパーツが「切れて」見える。
- 後で調整する前提なら、描き足しは最初から大きめにする。
- 線と塗りは、パーツごとに1レイヤーにまとめて取り込む（線画と塗りを別にしたまま取り込まない）。
- 元絵は直接加工せず、コピーをグループ化してマスクで切り抜き、新規レイヤーに描く。分割用PSDは、マスクとフォルダを残して保管する。
- PSDは Photoshop / CLIP STUDIO PAINT で作る。
- 解像度・キャンバスサイズの公式な指定は見つからなかった。

## 2. 部位別の切り分け（公式）
| 部位 | 切り分け・描き足し |
| --- | --- |
| 髪 | 前髪・横髪・後ろ髪に分ける。サイドテール、アホ毛など動かすものは単独。**他のパーツに隠れる部分まで描く** |
| 顔の輪郭 | **髪に隠れる部分も肌色で塗りきる。** 頭を丸く描くと立体的に見え、動きも付けやすい |
| 耳 | 輪郭から分ける |
| 目 | まつ毛・黒目・白目を分ける。**白目は全体を塗る**（黒目の裏が見えるため）。まつ毛は目尻の動くパーツと分ける |
| 眉・鼻 | それぞれ単独。大きくは変形しない |
| 口 | 上唇・下唇・口の中を分ける。口の中は元絵より一回り大きく描く。**唇の周りに肌色の塗りを足す**（口が線画からはみ出すため）。口にクリッピングは基本避ける |
| 首 | **大きめに描き、切り口が見えないようにする**（口の高さまで伸ばせば十分） |
| 胴 | 揺らすリボンなどは単独。襟・カーディガンも分けると質が上がる |
| 腕・脚 | 上腕・前腕・手、スカート・左右の脚に分ける |

## 3. 顔の向き（角度X・Y）のつくり方（公式・コミュニティ）
- 輪郭だけを表示して形を作ると判断しやすい（公式）。
- 構成の一例：目・鼻・口・輪郭を1つのデフォーマ（角度X）にまとめ、全体を頭の回転デフォーマ（首の付け根）に入れる。斜めの向きは「4隅自動生成」を使い、足りない所を手で補正する。
- 斜めでは縮み（斜め方向の潰れ）が出やすい。補間の拡張、隅の形の補正、回転デフォーマで対処する。首は丁寧な調整が要る。
- 大きな角度での回転は、複雑な絵ほど難しい（Live2Dの限界）。
- 【推奨】向きによって見え方が変わる面（奥側の頬・顎・耳・鼻筋・口）は、元絵に隠れている部分まで別パーツとして用意し、重なり順を決めておく。向きの端（±30°）で、輪郭の途切れや髪の隙間から下地が見えないかを必ず確認する。
- 【参考】Cubism 5.1 に3D的な変形の補助機能があるという記述があった。ただし初期のデフォーマ作成用という程度で、詳細は未確認。

## 4. 作り方の選択肢
- **A. 向きを絵で変えず、変形だけで作る**：元絵は1枚（正面）。描き足しは「隠れる面を塗り足す」まで。最も一般的。
- **B. 向きごとに差し替えパーツを描く**：今のプロジェクト（C・K・N・H・Eの下レイヤー）がこの方式。質は高くできるが、向きごとの絵を**同じ解像度・同じ線・同じ肌色で、輪郭を合わせて**描く必要がある。【推奨】
- **C. AIによるレイヤー分解**（Qwen-Image-Layered ＋LoRA の検証記事）：顔パーツ（目・眉・鼻・口）と素顔ベースの分離は1024pxなら実用的で、髪は1枚にまとまる。前髪・後ろ髪など細かい分割はできず、手作業か SAM のような分割モデルが要る。横顔は未検証。隠れた部分の補完は目視評価のみ。

## 5. 現在の素材をレビューするための確認項目
1. **解像度**：最終表示サイズの1〜2倍以上で、拡大せずに使えるか（今は拡大して耳・髪の縁がぎざぎざ）。
2. **隠れる部分の描き足し**：輪郭が髪の下まで肌色で塗られているか。首が口の高さまであるか。耳・髪の裏に抜けがないか。
3. **パーツの分け方**：髪が前・横・後ろに分かれているか。耳が輪郭から分かれているか。口は唇・口の中・周りの肌で分かれているか。白目が塗りきられているか。
4. **継ぎ目**：パーツ同士が、一定以上重なっているか（重なり幅が足りないと、動いたときに下地が剥き出しになる）。
5. **線と塗りの統一**：線の太さ・色・肌色・陰影が、全パーツと向きごとの差し替え素材で揃っているか（陶器の白に統一できるか）。
6. **縁の処理**：残留ピクセル、茶色の細い線、白い切れ端が、元素材の段階で無いか（コードで消す前提になっていないか）。
7. **向きごとの素材（方式B）**：見本との輪郭の一致、同一解像度、重なり順。±30°で破綻しないか。
8. **作り直しか、手直しか**：粗さの原因が「解像度」「描き足し不足」「向きごとの絵の不一致」のどれかを分けて判断する。解像度と描き足しは編集では直せないため、作り直しの対象になる。
