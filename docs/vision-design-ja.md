# シエルに画像を見せる（設計）

状態：1 枚の画像を見せるところを作る（2026-11-06）。画面共有はあとで。

## 1. 何をするか

持ち主が画像（イラスト・スクリーンショット・マイクラの画面など）をアプリから送ると、シエルがそれを見て、感想を言ったり、そのことで話したりできるようにする。

- 心のモデル（`gpt-5.4-mini`）は、文字と一緒に画像を読める。LiveKit Agents の `llm.ImageContent` に data URL で渡す。
- 料金：長い辺 1280 ドットほどの画像は、1 枚 1,000 トークン前後（`gpt-5.4-mini` の入力で 1 枚 0.1 円ほど）。作ったあとで、実際の値を測る。

## 2. 形

```
アプリ（Windows）：ファイルを選ぶ → 縮めて JPEG → LiveKit のファイル送信（topic ciel.image）
会話サーバー：目の係（eyes.py）が受け取る → 口（why image）→ 心が画像を見て返す
                                       → 軽いモデルが短い説明文を書く → あとの返事には説明文だけ
```

| 部品 | 中身 |
|---|---|
| アプリ `CielConversation.Image.cs` | 画像を選ぶ（Windows のファイルの選び方）、長い辺 1280 に縮めて JPEG（品質 85）、`SendFile`（topic `ciel.image`）。`image.state` で、受け取ったか・だめだった理由を表示 |
| `server/agent/eyes.py`（新規） | 受け取る（3 MB まで。JPEG・PNG・WebP だけ）。直近 3 枚をメモリーにだけ持つ（保存しない）。届いたら口の why `image` で、話の切れ目にシエルが見る |
| `mind.py` | 見ていない画像があるとき・「さっきの絵」のように画像を指したときは、心に回して、その返事にだけ画像を添える（小脳には添えない）。説明文は、心と小脳へ「[見せてもらった画像]」で渡す |
| `config/prompts/image_voice.md` | 画像を見たときの話し方 |
| `config/prompts/image_caption.md` | 説明文を書く係への指示 |

## 3. 決まり

- 画像を会話モデルに送るのは、届いたときの 1 回と、画像を指した話のときだけ。返事のたびには送らない。
- 説明文を書く係は、`detail: low`（安い見方）で 1〜2 文。
- 画像は保存しない。デバッグ用の会話ログにも、大きさと種類だけを残す。
- 画面のスクリーンショットには、通知やメールなどが写ることがある。シエルは、名前・連絡先・メッセージの中身などを読み上げない（`image_voice.md`）。
- Android は、画像を選ぶ部品が別に要るので、あとで。

## 4. あとで

- 画面共有（マイクラのゲーム画面・配信画面）：頼まれたときに、そのときの 1 コマを見る。
- クリップボードの画像、ドラッグ＆ドロップ。

## 5. 試したこと（2026-11-06）

- 開発用の会話サーバーで、Windows のアプリから画像（1280×720 ほどの JPEG、約 340 KB）を見せた。シエルは画像を見て感想を言った。
- 料金：画像を添えた心の返事は、入力がふだんより 1,000〜1,300 トークン増えた。説明文を書く係は 1,475 トークン（$0.0014）。1 枚あたり $0.002〜0.003（0.3〜0.4 円）ほど。
- 画面：「見せる」を下のボタンに足したら、スマホの幅（基準 390）で画面の外へ出た。下のボタンを「ほか（＋）・マイク・声の大きさ」の 3 つにし、画像を見せる・まとめ（議事録）は＋のメニューへ移した（`CielConversationUI.More.cs`）。機能が増えたら、このメニューに行を足す。
