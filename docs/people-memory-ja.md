# 人を覚える機能の使い方

更新：2026-10-18（日本時間）。シエルが声で人を見分け、名前とお話を覚えるしくみの、**使う人向けの手引き**。決めた理由と試験の結果は、[話者の識別](decisions/speaker-identification-ja.md)・[メモ](decisions/person-notes-ja.md)・[関係](decisions/person-relationship-ja.md)・[道具](decisions/tools-ja.md) の決定記録にある。

## できること

| できること | ふつう・おしゃべり | ひかえめ（会議など） |
|---|---|---|
| 声で、誰が話しているか見分ける | ○ | ○（全員の声が 1 本に混ざって届く） |
| 名前を聞く | 知らない声なら、シエルから一度だけ聞く | シエルからは聞かない。名乗られたときだけ |
| 名前と声、お話を覚える | 本人が同意したときだけ | 同じ |

覚えたことの出し方は、設定の「その場にいる人」で変わる：

| その場にいる人 | 覚えたこと（メモ） |
|---|---|
| ひとり | シエルから自然に話題にする |
| 身近な人 | シエルに渡しておくが、話題にするよう求めない。話の流れで自然に生かす |
| 人前 | 自分からは話題にしない（ほかの人に伝わるので）。本人に聞かれたら答える |
| 自動 | 会議につないでいれば人前、この会話で 2 人以上の声を聞いたら身近な人、それ以外はひとり |

おしゃべり度・その場にいる人は、アプリの設定の「声と会話」で選ぶ（[会議への参加](meeting-bridge-ja.md) の「会話のしかた」）。

## 覚えてもらう

1. シエルに名乗る：「シエル、私は博士です」（2 人で話していれば、シエルから「お名前を聞いてもいいですか？」と聞くこともある）。
2. シエルが「お名前と声、それからお話ししたことも少し、覚えておいてもいいですか？」と聞く。
3. 覚えてよければ「いいよ」と答える。断れば、その会話の間だけ名前で呼ばれ、何も保存されない。

覚えた人は、次の会話（接続し直したあと・別の日）でも声で分かり、名前で呼ばれる。名乗る前の数回の発言や、1 秒未満の短い発言は、うまく判定できないことがある。

## 覚えていること（メモ）

- 同意した人とのお話から、短いメモが残る（役割・シエルとの関係、好み、予定、接し方の好み、「覚えておいて」と頼んだこと）。予定は「来週」ではなく日付で残る。
- 残さないもの：健康・宗教・思想・性的指向・犯罪歴・民族・詳しいお金のこと（本人がはっきり頼んだときを除く）、ほかの人の個人情報、推測、その場かぎりの雑談。
- 「これ覚えておいて」と言うと、シエルがその場で覚える（待たされない）。言わなくても、会話の流れから大事なことは補われる。
- 2 人で話すとき、シエルは覚えていることを会話のネタにする（「発表、どうだった？」「今日もミルクティー飲んだ？」）。
- 声を前に覚えた人で、お話を覚えることへの同意がまだの人には、シエルが一度だけ「お話ししたことも少し覚えておいていいですか？」と聞く。

## シエルとの仲（関係）

- お話を覚えることに同意した人とは、話すたびに、シエルの中で「その人をどう思っているか」が育っていく。会話が終わるたびに、その日の会話を振り返って書き直される。
- 親しさは「はじめまして → 顔なじみ → 仲良し → 大切な人」と進む。何度もちゃんと話し、打ち明け話をしたり、気づかったりして距離が縮まったときに、1 つずつ上がる。下がることはない。
- 親しくなるほど、口調がくだけたり、甘えたり、気持ちを素直に言ったりするようになる。画面に数値は出ない（態度で感じてもらう）。
- からかいすぎたり約束を破ったりすると、次に会ったとき、ちょっとだけ拗ねていることがある。やさしくしたり謝ったりすると、すぐ機嫌が直る。しばらく会わないと、少し寂しがる。
- 「私のことどう思ってる？」と聞くと、シエルが自分の言葉で答える。人前では、気持ちの中身は話さない（口調にだけ表れる）。

## 確かめる・直す・忘れてもらう

声で頼めるのは**本人だけ**（ほかの人の分は頼めない）。

| したいこと | シエルへの言い方 |
|---|---|
| 覚えていることを聞く | 「私について何を覚えてる？」 |
| メモを忘れてもらう（別の人の話が混ざっていたときも） | 「紅茶のことは忘れて」「ルミナス王国の話は、私じゃなくて友だちの話だよ。忘れて」 |
| 呼び名を直す（聞き間違い・呼び方の変更） | 「博士じゃなくて、ハカセイです」「これからはハカセって呼んで」 |
| 人違いを直す（似た声の人と間違えられた） | 「私は博士じゃないよ、田中です」 |
| 声もメモもシエルとの仲もすべて忘れてもらう | 「私の声を忘れて」 |
| 今いる人を聞く | 「いま誰がいるの？」 |

人違いを直すと、その会話の間はその人として区別し直し、見本を集め直す。覚えてよいか聞かれたら答える。

## 管理（自宅サーバーで）

声でうまく直せないときは、自宅サーバーの `~/work/ciel-companion/server` で：

```sh
docker compose exec agent python speaker_admin.py list                     # 覚えている人の一覧（番号・見本の数・メモの数）
docker compose exec agent python speaker_admin.py notes <番号>             # その人のメモを見る
docker compose exec agent python speaker_admin.py relation <番号>          # シエルとの仲（段階・気持ち・気分）を見る
docker compose exec agent python speaker_admin.py rename <番号> <呼び名>   # 呼び名を直す
docker compose exec agent python speaker_admin.py delete <番号>            # 声もメモも仲も消す
docker compose exec agent python speaker_admin.py delete-all               # すべて消す
```

メモとシエルの気持ちは本人に関わる情報なので、見るのは管理が必要なときだけにする。

## 何を、どこに保存しているか

| 保存するもの | 場所 | いつまで |
|---|---|---|
| 名前、同意した日時、最後に話した日時 | 自宅サーバーの DB（`people`） | 本人が「忘れて」と言うか、管理で消すまで |
| 声の特徴（192 個の数。録音ではなく、元の声は戻せない） | 同（`voiceprints`、1 人 30 個まで） | 同 |
| その人のメモ（短い文） | 同（`person_notes`、1 人 50 件まで） | 同。メモだけ消すこともできる |
| シエルとの仲（親しさの段階、シエルの気持ちの短い文、一時的な気分） | 同（`person_relationship`、1 人 1 行） | 同 |
| 判定のための声 | 会話サーバーのメモリー（直近 30 秒） | 古いものから捨てる。ファイルや DB には書かない |
| 名前を聞いていない人・同意しなかった人の声の特徴 | 会話サーバーのメモリー | その会話の間だけ |

- DB は自宅サーバーの中だけで、外から入る口は開けていない。ログには名前もメモの中身も出さない（番号と件数だけ）。
- 声は会話のために OpenAI（Realtime API）へ送っている。メモを書くときは、最近の会話の文字起こしを OpenAI の文字のモデルへ送る。
- 仕様書 8 章（保存するもの）にも書いてある。

## うまくいかないとき

| 症状 | 考えられること・対策 |
|---|---|
| 覚えたはずなのに、名前で呼ばれない | 発言が短い（1 秒未満）。少し長めに話す。続くなら、会話サーバーのログ（`docker compose logs agent`）の「話者：覚えている人 #番号（類似度）」を見る。基準は `CIEL_SPK_MATCH`（既定 0.45） |
| 似た声の人と間違えられる | 「私は○○じゃないよ」で直す。ほとんど同じ声の 2 人は、声だけでは区別しきれない（シエルは「たぶん」として断定しない） |
| 名前やメモの言葉がおかしい（「シエル」が「CL」など） | 文字起こしの聞き間違い。ヒントで減らしてある。メモは「それは忘れて」か管理で消す |
| ほかの人の話を、自分のことのように言われる | 「それは別の人の話だよ、忘れて」で消える。ひかえめのときも、発言ごとに声で話者を決めて、本人の発言だけをメモにしている（2026-10-18）。似た声の人の発言は「たぶん」になり、メモにはならない |
| 覚えておいてと言ったのに残っていない | 本人だと確かに分かっていなかった（「たぶん」の判定）か、お話を覚える同意がまだ。`speaker_admin.py list` でメモの数を確かめる |
