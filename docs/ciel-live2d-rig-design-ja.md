# シエルのリグ設計書（第 1 段階、2026-10-11 案）

根拠：`ciel-live2d-reference-rig-analysis-ja.md`（公式サンプルの解析）、`ciel-live2d-rebuild-analysis-plan-ja.md`（計画）、`ciel-design-constraints-for-parts-ja.md`（キャラクター設計）。
ユーザーの確認を受けてから、段階 2（生成条件の確認）・段階 3（素材）へ進む。

## 1. 目標
- 角度X・Y の ±30 は、見た目で 15〜20° 程度の向き（お手本の ±15° 相当）。公式サンプルと同じ考え方。
- 顔の正面の見た目は、確定原画と同じ。向きを変えても、継ぎ目・下地・切れ端が見えない。
- 視差：奥のもの（後ろ髪・横の毛束）は小さく、または逆に、手前のもの（鼻・口・眉）は大きく動く。

## 3. デフォーマの木
公式サンプルと同じ形。格子は 5×5（細部の補正が必要な輪郭だけ 6×6 まで）。
```
Body_Z（BodyAngleZ）
 └ Body_Y（BodyAngleY）
    └ Breath（Breath）
       ├ Torso_X（BodyAngleX）── 胴・ベルト・宝石・上着の各ワープ
       ├ Back_Hair_Root … 後ろ髪の下側（肩の後ろの毛束）は体に付ける
       └ Neck_Pos［回転］（BodyAngleX）
          ├ Neck_Warp（AngleZ、AngleY）── 首・首輪（首輪は首と一緒）
          └ Head_Rot［回転、首の付け根が中心］（AngleZ）
             ├ Face_XY（X×Y）── 輪郭の塗り
             │   └ Face_Line_XY（X×Y）── 輪郭の線（上向きで顎の線を薄く）
             ├ Eye_L_XY／Eye_R_XY（X×Y）── 目の各層 └ EyeBall_*（EyeBallX×Y）
             ├ Brow_L_XY／Brow_R_XY（X×Y）└ Brow_*_Pos（BrowY）└ Brow_*_Angle
             ├ Nose_XY（X×Y）
             ├ Mouth_XY（X×Y）└ Mouth_Shape（MouthOpenY×MouthForm）
             ├ Cheek_L_XY／Cheek_R_XY（X×Y）
             ├ Hair_Front_XY（X×Y）└ Hair_Front_Z（AngleZ）└ 毛束ごとの揺れ（物理）
             ├ Hair_Side_L_XY／Hair_Side_R_XY（X×Y）└ 内側・外側の揺れ（物理）
             ├ Hair_Crown_XY（X×Y）── 頭頂・アホ毛（アホ毛は子の揺れ）
             ├ Ear_L_XY／Ear_R_XY（X×Y）└ Ear_*_Move（ParamCielEar*）
             └ Hair_Back_Upper_XY（X×Y）└ 揺れ
```
- 首は頭とグルーでつなぐ（首の上端を顎の裏へ）。公式サンプルの肩のグルーと同じ考え。
- 角度X・Y は 3×3 キー（−30・0・30）。中間の ±15 が不自然なときだけ 5 点にする。
- 物理演算の出力は、向きのワープの子で受ける（向き → Z → 揺れ）。

## 5. 描画順（大きいほど手前）
後ろ髪 100 → 体 150〜250 → 首 300 → 首輪 320 → 横髪の外側 350 → 犬耳 380 → 頭頂 400 → 輪郭 500 → 頬 520 → 鼻・口 540 → 目 600〜660 → 横髪の内側 700 → 前髪 750 → 眉 800（前髪越しに見せる場合は不透明度で調整）→ アホ毛 820。
第 1 段階の角度の範囲では、向きによる描画順の切り替えは使わない（ひよりと同じ）。

## 6. 第 2 段階で足す素材の候補（今回は作らない）
奥の頬の丸み、顎の裏（上向きで見える面）、横向きの鼻、耳の付け根の裏。第 1 段階の確認で必要なものだけ作る。

## 7. 決定事項と、比べて決めること（2026-10-11）
1. パーツの分け方（2 章）と約 100 メッシュ：了承。
2. 犬耳の感情表現：付ける。`ParamCielEarL/R`（−1 伏せる／0 通常／1 立てる）を、向きのワープの子のワープで作る。表情（`smile`・`troubled`・`surprised`）から動かす。
3. 眉と前髪の重なり：次の 2 案を、素材ができた段階（段階 3 の後）に同じモデルで作り、`render-moc.py` の静止画と、向き・前髪の揺れを動かした動画で比べて決める。

| | 案 A：眉を前髪の上に置く | 案 B：前髪の下に置き、前髪越しに透かす |
| --- | --- | --- |
| 作り方 | 眉を前髪より手前の描画順にする（不透明度で濃さを調整） | 眉は前髪の下（本来の奥行き）。眉の複製を、前髪のメッシュでクリッピングし、不透明度 30〜60% で前髪の上に重ねる |
| 長所 | 簡単。表情が常にはっきり読める（アニメの一般的な描き方） | 奥行きが正しい。前髪の毛束の上で眉が自然に薄くなり、髪の質感を保つ。目にも同じ方法を使える |
| 短所 | 眉が前髪の線の上に乗って浮いて見えることがある。眉と前髪の動きの量が違う（眉 0.075、前髪 0.045）ので、向きを変えると眉が髪の上を滑る | メッシュが増える（左右の複製 2〜4 枚）。前髪が揺れると、透ける範囲が変わる（自然だが、確認が要る） |
| 確認すること | 向き ±30 と前髪の揺れで、眉が浮いて見えないか | 透ける濃さ（表情が読めるか）、クリッピングの縁 |

案 B は、目（まつげ）が前髪にかかる所にも同じ方法を使えるので、両方を同時に試す。
