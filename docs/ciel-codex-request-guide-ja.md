# Codex（ChatGPT）へのパーツ素材の頼み方

シエルの Live2D 素材を Codex に頼むときの手順とコツ。2026-10 の作り直しで、うまくいった頼み方・崩れた頼み方から分かったことをまとめる。
役割分担：素材の生成・組み立ては Codex、リグ・Unity・道具は Claude、区切りでの判断はユーザー。

## 1. いちばん大事なこと：部品を白紙から描かせない

画像の生成は、「絵全体の中で自然に見えるか」で形を決める。周りの無い部品だけを白紙から描かせると、比率・丸み・線の基準を失って崩れやすい。
**承認済みの絵を元に、違いが最小限になる「編集」として頼む**か、**物を丸ごと 1 枚で描かせて、こちらで切り分ける**。

| 頼み方 | 結果 | 例 |
| --- | --- | --- |
| 承認済みの絵を少しずつ編集し、最後に切り出す | うまくいった | 顔の土台 v21：横髪を取り除く → 目・口などを消す → 単色の背景から切り出す。見えていた顎の線は 1〜3 px の差で保たれ、隠れていた頬だけが自然に補われた |
| 全体の中で描かせて、その部品だけを切り出す | うまくいった | 口 v14：口を閉じた顔の中で口を描かせ、口だけを透明素材にした |
| 物を 1 枚の絵として描かせ、こちらで前後に切り分ける | うまくいった | 首輪・上着 v16：首輪だけ・上着だけを、着ていない状態で丸ごと描かせ、マスクで前後に分けた |
| 部品だけを白紙から描かせる | 崩れた | 顔の土台 v20：顎がすっきりしすぎて、元のかわいさが失われた。体 v15：腕・体型が崩れた |
| プログラムで描き足す・塗る・変形する | 崩れた | v7 の切り抜き、v15 の継ぎ足し：直線的で不自然になる |

## 2. 依頼文の型

依頼文はファイルに書き（`.local/codex/req-NN-名前.md`）、`scripts/codex/run-codex.ps1` で渡す（3 章）。次の見出しで書く。

1. **背景**：何のための素材か、今の何が問題か（ユーザーの指摘はそのまま引用し、印を付けた画像があれば `inputs/` に置いて渡す）。
2. **元にする絵**：承認済みの組み上げ画像（キャンバス 2172×2896）。顔だけなら切り出して拡大してよい、戻すときは逆の変換で置く、と書く。
3. **段階ごとの編集**：1 段階に 1 つの変更。各段階に次の 3 つを書く。
   - 変えること（例：頬にかかる横髪の束だけを取り除き、隠れていた頬を自然に補う）
   - **変えてはいけないこと**（例：見えている顎・頬の線、目・鼻・口・前髪・耳）
   - 確かめ方（前の段階と重ねて、変えてはいけない所が変わっていないか）と、生成し直す回数の上限（4 回）
4. **切り出し**：単色の背景（例：#00FF00）との境目で透明 PNG にする。切り分けるだけで、描き足し・塗り・形の変形はしない（色の差から決めるアルファはよい）。
5. **置き方**：キャンバス 2172×2896 の、今の層と同じ位置へ、**縦横同じ倍率の拡大縮小と移動だけ**。ほかの層とずれないこと。
6. **確認図**：元／各段階を並べた図、新しい部品で組み上げた正面（`assets/ciel/current/layers.json` の順で、その部品だけ差し替え、`visible: false` は除く）と今の組み上げの比較、問題の所の拡大、部品単体を暗い背景で並べた図。
7. **書き込み先**：`assets/ciel/generated/vNN/` と `scripts/live2d/vNN/` の中だけ。`assets/ciel/current/` は変えない。報告は `assets/ciel/generated/vNN/report.md`。

共通の条件（毎回書く）：
- 生成で自然に描く。プログラムで画素を描き足す・塗る・変形する加工はしない。
- 白磁の肌・薄い青紫の細い輪郭線など、元の絵の色と線に合わせる。
- 体型は 13 歳くらいの自然な体型（元の絵に合わせすぎない所はそう書く）。

実例：`.local/codex/req-45-face-base-edit.md`（顔の土台を編集で作る）。生成物は、採用した物を `assets/ciel/current/` へ入れたあと、`.local/archive/codex-generated/vNN/` へ移す（Git の外。v20・v21 の報告・確認図・試した絵はそこにある）。

## 3. 依頼の実行

```
powershell -File scripts/codex/run-codex.ps1 -PromptFile .local/codex/req-NN-名前.md -Out .local/codex/res-NN.md
```
- 続きを頼むときは `-Resume <session id>`（ログ `res-NN.log` の "session id:" の行）。VS Code の Codex で同じ会話を開いていると resume できない。
- 時間がかかる（数十分）。Claude からはバックグラウンドで実行し、終わったら返答（`res-NN.md`）・報告・確認図を読む。
- Codex が画像の加工を断ることがある。そのときは、何をしてよいか（切り出しは色の差から決めるアルファでよい、など）をはっきり書いて頼み直す。

## 4. 受け取った後（Claude）

1. **判断は組み上げた絵で**：部品単体ではなく、組み上げた正面と、Live2D で動かした見た目で決める。数値だけで良いとしない。ユーザーに比較図を見せて判断してもらう。
2. **隣の層との色**：新しい部品の色が少し変わると、同じ色で塗られた隣の層との継ぎ目が浮く（例：顔の土台を変えたら、口・まぶたまわりの肌色の層が四角く浮いた）。形には触れず、色の差の分だけ隣の層の色をずらす（`scripts/live2d/recolor-skin-layers.py`）。
3. **単色の背景から切り出した線**：境目の色が緑の補色（赤紫）に寄ることがある。気になる場合は伝える。
4. **current へ入れる**：`assets/ciel/current/layers/` の同じ名前の PNG を置き換える（古い版は残さない）。
5. **Cubism へ入れる**：元の PSD と同じレイヤー名・同じ順の PSD を作り、「差し替え」で取り込む。
   - 元の層の画像は、`.cmo3` の中（CAFF の `imageFileBuf_N.png`、全キャンバスの PNG）から取り出せる。顔まわりは `ciel-v14c.psd`、体まわりは `ciel-v19-body.psd`。
   - PSD は `scripts/live2d/gimp/build_layers_psd.py`（`visible` も反映）で作る。
   - Cubism で PSD を開き、モデルを選び、「[ciel-v14c.psd] を差し替え」。保存時の「未使用の原画を削除しますか」は「はい」。
   - 部品の形が変わったら、メッシュも作り直す（顔の土台は `scripts/live2d/remesh-face-contour.py`）。
