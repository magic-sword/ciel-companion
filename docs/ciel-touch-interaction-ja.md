# シエルに触れる（タッチの反応）

2026-10-15 作成。会話アプリ（Realtime API ＋ Irodori-TTS）で、画面のシエルに触れると、体がその場で反応し、シエルが声で反応を返す。

## 流れ

1. Unity の `CielTouch`（シエルのモデルに付ける）が、タップ・なぞりを Cubism の当たり判定で調べる。触れた点で絵が描かれている（不透明な）部品のうち、いちばん手前のもので部位を決める。
2. その場で体を動かす（下表）。表情は会話サーバーの表情が無いときだけ短く切り替える。
3. `CielConversation.SendTouch` が LiveKit のデータのメッセージ（topic `ciel.touch`）で会話サーバーへ知らせる。
   例：`{"v":1,"type":"user.touch","part":"head","gesture":"stroke","phase":"start","duration_ms":0}`
4. 会話サーバーの `touch.py` が「[タッチ] 頭を撫でる（撫で始めた）」の 1 行を会話モデルへ渡し、返事を作らせる（`generate_reply(user_input=…)`。会話の履歴に残る）。返事は通常どおり感情の印つきで Irodori-TTS が読み上げ、表情も切り替わる。受け取り方は `config/prompts/touch.md` で教える。

しぐさは tap（短く触れる）・stroke（なぞる。画面の高さの 5% 以上動かす）・hold（0.4 秒以上動かさずに触れる）。
stroke は始まり（start）と終わり（end）、tap・hold は離したとき（once）に送る。
前の返事から 4 秒以内のタッチには返事をしない。シエルが話している・考えている間は、終わるのを待ってから返す。撫で始めで知らせたら、撫で終わりでは知らせない。

### 誰が触ったか（2026-10-17）

人は声でしか見分けられないので、触れた前後に話した人から推し量る（`touch.py`）。

1. 触れたときに人が話していたら、その発言への返事に「[タッチ] 頭を撫でる（いま話した人が、話しながら触れた）」を添える。発言の [発言者：…] の人が触ったと分かる。おしゃべり度がひかえめで呼ばれていなくても、返事を作らせる。
2. 話していなければ、待たずに、1 分以内に話した人を「触ったのは、たぶんハカセさん（少し前に話していた人）」として添えて返す。撫でている最中に反応できるよう、話し始めるのを待たない（はじめは 1.5 秒待っていたが、返事ができる前に撫で終わってしまった）。会議につないでいるときは添えない（会議の向こうの人は画面に触れられない）。
3. どちらでもなければ、名前を添えずに返す。シエルは名前を当てずっぽうで呼ばない（`config/prompts/touch.md`）。

話しながら触れたのに発言が文字にならなかったときは、10 秒で諦めて、タッチだけで返す。端末の持ち主（スマホは持っている人が触ることが多い）を設定で選べるようにするのは、次の段階。

## 部位と体の反応

| 部位（部品） | その場の反応 |
|---|---|
| 頭（`Hair_Crown`・`Hair_Front_*`・`Hair_Ahoge`） | 撫でると少しうつむき、指の左右の動きに頭がついていく。耳が寝て、にこにこ。前髪は物理演算で揺れる。つつくと頭が小さく沈み、耳がぴくっと動く |
| 耳（`Ear_*`） | 耳がぴくっと動く。つつくと驚き、撫でるとにこにこ |
| ほっぺ・顔（`Face_*`・`Cheek_*` など） | つつかれた側から頭が少し逃げて驚く。撫でると照れ |
| 髪（`Hair_Side_*`・`Hair_Back`） | 触れた髪の物理演算の粒子を指の動きの方向へ押し、自然に揺れて戻る。なぞると照れ |
| 肩（`Jacket48_Fur_*`・`Jacket52_FurBack_*`・`Jacket48_SleeveUpper_*`） | 触れた側の毛皮がばねで揺れ、触れられた方を振り向く |
| 手・腕（`Body48_Hand*` など） | 嬉しい・照れ |
| 胸・おなか・首・襟（その他の部品） | 反応しない。奥の髪にも当たらない |

どの部位でも、触れている間は目線が触れた点へ向く。髪の揺れは Cubism の物理演算（`PhysicsSetting1〜3`）の粒子の速度を足すため、演算の設定どおりに揺れて止まる。頭の角度も物理演算の入力なので、撫でたときの頭の動きで髪も揺れる。


## 触れている点の表示

2026-10-16 追加。`CielTouchVisual` が `CielTouch` のイベント（`Pressed`・`Dragged`・`StrokeStarted`・`Released`）を受け取り、会話の画面の層（画面の暗がりの上、ボタンや文字の下）に描く。部位を判定する処理は `CielTouch` だけが持つ。
見た目は企画設計の「シエル主観視界」（`D:\CIEL\企画設計\キャラ\シエル\設定資料_シエル主観視界_AR知覚.md`）の決まりに合わせる。基調色はシアンで、形は細い光の縁と角の丸い六角形（Ciel Prism の形）。選んだときは光が外から中心へ集まり、明滅は呼吸のように弱くする。共感の色は淡い琥珀色で、赤（危険の色）と照準のような形は使わない。
シエルの体は白いため、光を足して白く見せる描き方はしない。濃いシアンの光を重ね、その下に薄い紺のにじみを敷いて見分けやすくする。

| 状態 | 表示 |
|---|---|
| 反応する部位に触れ始める | 光の輪が外から指先へ縮まって集まり（0.22 秒）、芯の光と一緒に指についていく |
| 長く触れる | 0.1 秒後から、六角形の輪が tap とみなす長さで一周して満ち、そのあとは呼吸するように明滅する。指が動き始めたら消す |
| なぞる | 指の後ろに、先細りで 0.4 秒で消える光の軌跡を描く。なぞりと判定された瞬間に輪が少しふくらんで軌跡が明るくなり、撫でる強さに合わせて琥珀色へ寄る |
| tap で離す | 丸い輪が広がりながら六角形の輪へ移り変わって消える波紋 |
| hold・stroke で離す | 光が少し広がりながら 0.25 秒で消える |
| 反応しない部位 | 暗いシアンの細い輪が一瞬だけ出る |
| 画面のボタンの上 | 何も出さない |

輪の画像 `touch_ring.png`（小さく表示しても線がかすれない太さ）と六角形の輪の画像 `hex_ring.png` は、`scripts/ui/make_ui_sprites.py` が作る。
共感の琥珀色は、会話の画面の琥珀色（#FFC46B）のままだと白い髪の上で見えなかったため、少し深い #F0A845 にした。軌跡の下にも薄い紺のにじみを敷く。
[状態ごとの表示](../assets/ciel/rig/proofs/touch/visual-states.png)：左から、触れ始め・長く触れる・撫で始め・撫で続ける・ほっぺをつつく・胸に触れる。[頭を撫でているときの画面全体](../assets/ciel/rig/proofs/touch/visual-stroke.png)。
好意を示すハートなどの飾りは描かず、シエルの体の反応で見せる。胸のプリズムを撫でている間に光らせる案は、後で検討する。

## 当たり判定の範囲

部品のメッシュは絵より大きく、透明な余白を含む。横髪のメッシュは顔と肩の上まで広がっているため、メッシュの形だけで判定すると、ほっぺや肩に触れても髪になっていた（2026-10-15 のユーザーの確認）。
現在は、メッシュに当たった点の UV からアトラスの不透明度を調べ、不透明度 0.5 以上の部品だけを数える。アトラスは CPU から読めない設定のため、初回の判定時に GPU で 1024×1024 に縮小コピーし、不透明度だけを持つ（1 枚 1MB）。
[部位ごとの判定の範囲](../assets/ciel/rig/proofs/touch/hit-areas.png)：赤＝頭、橙＝耳、桃＝ほっぺ・顔、青＝髪、緑＝肩、黄＝手・腕、色なし＝反応しない。
確認用の画像は `CielTouchCheck.RunMap` で作れる。

## 確認

- Unity：`CielTouchCheck.Run`（`-batchmode` なしで Unity.exe から実行）が会話シーンを再生し、7 通りの触れ方の判定・知らせの内容・体の反応を確かめる。[反応の一覧](../assets/ciel/rig/proofs/touch/reactions.png)、[記録](../assets/ciel/rig/proofs/touch/verification.txt)。赤い丸が触れた点。
- 触れている点の表示：`.local/render-check/playmode-request` に `touch` と書いて Unity.exe を起動すると（`CielPlayModeShot`）、縦長の画面で触れ始め・長く触れる・頭を撫でる・ほっぺをつつく・胸に触れる、の順に再現して撮る（`.local/render-check/touch-*.png`）。[記録](../assets/ciel/rig/proofs/touch/visual-verification.txt)。
- 会話サーバー：偽の会話で、知らせの文面、返事をしない条件（話し中・間隔）、撫で終わりでの返事、不正なメッセージの無視を確かめた。`touch.py` を含めて `agent.py` を読み込めることも確認した。
- 未確認：実際の会話での声の反応の自然さ。会話モデルが知らせの文面を読み上げないか、反応が単調にならないかは、実際に触れて確かめる。
- 今の会話シーンの映し方では手が画面の下に切れているため、手には触れられない。
