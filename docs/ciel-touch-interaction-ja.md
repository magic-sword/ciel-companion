# シエルに触れる（タッチの反応）

2026-10-15 作成。会話アプリ（Realtime API ＋ Irodori-TTS）で、画面のシエルに触れると、体がその場で反応し、シエルが声で反応を返す。

## 流れ

1. Unity の `CielTouch`（シエルのモデルに付ける）が、タップ・なぞりを Cubism の当たり判定で調べる。触れた点でいちばん手前に見えている部品で部位を決める。
2. その場で体を動かす（下表）。表情は会話サーバーの表情が無いときだけ短く切り替える。
3. `CielConversation.SendTouch` が LiveKit のデータのメッセージ（topic `ciel.touch`）で会話サーバーへ知らせる。
   例：`{"v":1,"type":"user.touch","part":"head","gesture":"stroke","phase":"start","duration_ms":0}`
4. 会話サーバーの `touch.py` が「[タッチ] 頭を撫でる（撫で始めた）」の 1 行を会話モデルへ渡し、返事を作らせる（`generate_reply(user_input=…)`。会話の履歴に残る）。返事は通常どおり感情の印つきで Irodori-TTS が読み上げ、表情も切り替わる。受け取り方は `config/prompts/touch.md` で教える。

しぐさは tap（短く触れる）・stroke（なぞる。画面の高さの 5% 以上動かす）・hold（0.4 秒以上動かさずに触れる）。
stroke は始まり（start）と終わり（end）、tap・hold は離したとき（once）に送る。
シエルが話している・考えている間、相手が話している間、前の返事から 4 秒以内は返事をしない。撫でている途中で返せなかったときは、撫で終わりで返す。

## 部位と体の反応

| 部位（部品） | その場の反応 |
|---|---|
| 頭（`Hair_Crown`・`Hair_Front_*`・`Hair_Ahoge`） | 撫でると少しうつむき、指の左右の動きに頭がついていく。耳が寝て、にこにこ。前髪は物理演算で揺れる。つつくと頭が小さく沈み、耳がぴくっと動く |
| 耳（`Ear_*`） | 耳がぴくっと動く。つつくと驚き、撫でるとにこにこ |
| ほっぺ・顔（`Face_*`・`Cheek_*` など） | つつかれた側から頭が少し逃げて驚く。撫でると照れ |
| 髪（`Hair_Side_*`・`Hair_Back`） | 触れた髪の物理演算の粒子を指の動きの方向へ押し、自然に揺れて戻る。なぞると照れ |
| 肩（`Jacket48_Fur_*`・`Jacket52_FurBack_*`・`Jacket48_SleeveUpper_*`） | 触れた側の毛皮がばねで揺れ、触れられた方を振り向く |
| 手・腕（`Body48_Hand*` など） | 嬉しい・照れ |
| 胸・おなか・首・襟（その他の部品） | 反応しない。奥の髪にも当たらない |

どの部位でも、触れている間は目線が触れた点へ向く。髪の揺れは Cubism の物理演算（`PhysicsSetting1〜3`）の粒子の速度を足すため、演算の設定どおりに揺れて止まる。頭の角度も物理演算の入力なので、撫でたときの頭の動きで髪も揺れる。


## 確認

- Unity：`CielTouchCheck.Run`（`-batchmode` なしで Unity.exe から実行）が会話シーンを再生し、7 通りの触れ方の判定・知らせの内容・体の反応を確かめる。[反応の一覧](../assets/ciel/rig/proofs/touch/reactions.png)、[記録](../assets/ciel/rig/proofs/touch/verification.txt)。赤い丸が触れた点。
- 会話サーバー：偽の会話で、知らせの文面、返事をしない条件（話し中・間隔）、撫で終わりでの返事、不正なメッセージの無視を確かめた。`touch.py` を含めて `agent.py` を読み込めることも確認した。
- 未確認：実際の会話での声の反応の自然さ。会話モデルが知らせの文面を読み上げないか、反応が単調にならないかは、実際に触れて確かめる。
- 今の会話シーンの映し方では手が画面の下に切れているため、手には触れられない。
