# 顔の立体感・頬のもちもち感：調査と編集方針（引き継ぎ用）

作成：2026-10-09。実装の記録は `ciel-live2d-production-spec-ja.md` の 12.31〜12.33。ここは、**調べた根拠と、そこから決めた方針**をまとめる。

## 1. 目的
- お手本（`assets/ciel/generated/pose-ref/`、25 向き）の立体感に近づける。特に、(a) 鼻頭が頂点で、鼻筋と頬が山折りになる立体感、(b) 左右を向いたときの頬のもちもち感。
- 現状（12.33 時点）：頭を丸い断面＋凹凸の 3D モデルで回している。目・耳の動きは見本に近いが、頬の輪郭のふくらみと、肌の外形の切れ方は未解決。

## 3. 方針（調査と、ここまでの実験から）

1. **形は 3D モデルで計算する**（採用済み）：丸い断面＋鼻筋・頬・口もとの凹凸で格子の頂点を回し、正射影する。X と Y が足し算にならない斜めも、これで作る。出典 2・9 に合う。
2. **頬は、別の動きを持たせる**：出典 4・5 に従い、頬の領域は、深さを増やすだけでなく、**向いた側の輪郭を外へふくらませ、奥側の頬は細くカーブさせる**。
3. **輪郭の外形は、見本から測る**：見本の肌の輪郭（頬から顎）を向きごとに抜き出し、肌の画像の外形をそれに合わせる。
4. **鼻は折れ目で分ける**：出典 6。鼻筋の折れ目（鼻頭の位置）を境に、鼻の左右が別に動くようにする。肌の画像に鼻の線があるので、分けるには、追加素材が必要か検討する（5 章）。
5. **頬の赤みは別レイヤーにする**：出典 7。素材が要る（5 章）。
6. **描画順の切り替え**：出典 8。耳・髪が前後する。
7. **遠近**：出典 2。奥を細く、手前を広くする。
8. 確認は、`preview-pose.py`・`preview-vs-ref.py`（Python の近似、数秒）→ Unity の `CielRenderCheck`・`eval-pose-grid.py`（最終）。

## 4. 作業の手順（再現用）
1. `scripts/live2d/head3d-keys.py` の定数（`PROFILE_K`、`CHEEK_*`、`NOSE_*` など）を調整し、`python -I scripts/live2d/head3d-keys.py 入力.cmo3 出力.cmo3` で 25 キーを作る（入力は、Head_Warp が 16×16 で、角度 X・Y が 5×5 のもの）。
2. `python -I scripts/live2d/preview-vs-ref.py 出力.cmo3 比較.png xL30_y0,xR30_y0,...` で、見本と並べて見る。
3. 良ければ、Cubism を再起動して、その .cmo3 だけを開き、アトラス編集（ctrl+t）→ OK → 書き出し（ctrl+alt+s）。メモリ不足を避けるため。
4. Unity で `CielRenderCheck` を回し、`compare-pose.py`・`eval-pose-grid.py` で確認する。
