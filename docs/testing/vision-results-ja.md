# 画像入力の実測

> 責務：画像API・会話添付の実測条件、改善結果、残課題、生データ。

[評価の見取り図](benchmark-guide-ja.md#画像入力)と[画像入力の設計](../services/vision-design-ja.md)から読む。合成図形の疎通確認と実画像の認識精度を区別する。

## 現在の判断

合成図形・白紙を使うGPU併用APIの6要求は期待した応答に一致した。常設APIへ256pxの前処理とCPU画像エンコーダーを反映し、開発の画像添付から返答テキスト・音声の受信まで17.436秒を1回確認した。写真・細かい日本語文字・Minecraft画面の位置指定は未測定で、合成画像の成功率を一般的な画像認識精度としない。

## ローカルQwenの画像入力

2026-11-10、自宅サーバーで既存`Qwen3.5-35B-A3B-Q4_K_M.gguf`に画像用重みを追加し、隔離APIで画像入力を確認した。LLMファイルは22,016,023,168 bytes、SHA-256は`3b46d1066bc91cc2d613e3bc22ce691dd77e6f0d33c9060690d24ce6de494375`。[Unslothの同系列GGUF](https://huggingface.co/unsloth/Qwen3.5-35B-A3B-GGUF/tree/bc014a17be43adabd7066b7a86075ff935c6a4e2)のQ4_K_Mと一致する。

同リビジョンの`mmproj-F16.gguf`（899,283,648 bytes、SHA-256 `a516ab92e8240da4734d68352bdfba84c16e830ee40010b8fac80d69c77272ff`）を取得・検証し、サーバー`~/models/llm/mmproj-F16-Qwen3.5-35B-A3B.gguf`へ配置した。隣接`.json`が取得元と指紋の台帳。実行イメージは`sha256:075d738d0622c9f1cfd9571442a9436d60a577b35e42445c3ba099e2e8dc64da`、llama.cpp build 11118 / commit `e6ab7c1a4`。既存イメージと重みを維持したまま画像APIが起動した。

最初に4,096トークン・1枠・8CPU上限のCPU専用コンテナで、図形画像と白紙の2要求を正しく認識した。256pxの図形は最初のトークン約1.869秒・完了4.608秒、白紙は1.928秒・3.919秒。これはCPU専用構成の測定で、GPU構成との厳密な一変数比較ではない。

続いて言語側は通常と同じGPU併用（MoE専門家はCPU）、画像エンコーダーは`--no-mmproj-offload`でCPU、1要求32,768トークン・2枠・16CPU上限、`--image-max-tokens 1024`で試験した。試験ポートはloopbackの8098。GPUの重複確保を避けるため、共有8094は一時的にCPUで処理し、終了後にGPUへ復帰した。共有APIのコンテナ、Compose、supervisor、agentの設定は変更していない。

最新のGPU併用試験では、赤丸と青四角・色と形を入れ替えた図形・白紙、解像度違いと再送を含む6要求が正解と一致した。**単純な合成画像の疎通確認であり、一般的な認識精度100%を示すものではない。** 初回の画像はキャッシュ0、再送だけ124トークンのキャッシュを使用した。

同じAPIの文字のみの短いOK要求は0.330秒（2出力トークン）。画像要求とは出力量が異なるため、直接の速度倍率にはしない。画像回答のデコードは約33～34トークン/秒だった。GPU全体の処理中ピーク10,756MiB、空き最小1,180MiB。これはTTS等を含む全体値で、ロード時の瞬間ピークや画像機能だけの追加VRAMではない。試験コンテナのcgroup memory.peakは2,499,866,624 bytesだが、共有mmapページの課金先が異なるため、モデル全体のRSSや追加物理RAMとは扱わない。

写真、細かい日本語OCR、画面の小さなUI、Minecraftの実画像、画像と会話の同時要求、歌唱中の負荷は未測定。エンコーダーのGPU配置も未試験。256pxの良好な結果だけで高解像度や位置検出の品質を保証せず、縮小と入力トークン制限の精度への影響を別途評価する。

再実行用は`scripts/server/probe-local-vision.py`。最新試験のスクリプトSHA-256は`1b81dc9ff8ca7c2de3f3a9802027a51a6e82ea672fba38326e034e0f843cea79`、Git基点は`069e3442b821461f96dc60eeb2bc2c54a5d58d30`で、このスクリプトは試験時点では未コミット。生データはサーバー`~/work/ciel-companion/server/local-llm/data/vision-cpu-20261110T004727Z/`と`vision-gpu-20261110T005235Z/`、モデル指紋は同階層`vision-model-provenance.json`。手元の回収先は`.local/vision-validation/20261110/`で、report.json、合成PNG、server.log、projector.jsonを保持する。小さい画像だけの先行GPU試験`vision-gpu-20261110T004838Z/`とは別の実行として保存した。

全試験コンテナを削除し、共有APIがGPU・ready・32k×2枠へ戻ったこと、通常の文字要求が返答すること、本番・開発エージェントの稼働と再起動回数0を確認した。これは前処理のない隔離API測定を終えた時点の復元確認であり、以後の常設API導入・画像添付の実測とは分けて扱う。

## 常設画像APIの256px前処理

2026-11-10、`cd179834a33f97d873e079b047fc09e6554e1cf9`のAPIと画像経路を反映し、添付試験で見つかった通知のみのQwen入力・並列画像説明の問題を`f2028e830c275d9fd6b84bd2f6177323c1255351`で修正して両agentへ配布した。最初の人の発話より前の通知には、実際の内部通知をQwenの送信用queryとして添える。ローカルの画像説明は利用者向け返答の生成完了後に開始し、同じCPU・モデルと競合させない。保持外の画像の説明は開始しない。

受信口`gateway.py`の既定256px、向き補正、縦横比維持、拡大なし、透過とメタデータの除去、不正画像拒否、複数画像、文字のみ、SSE中継、上流停止をテストした。画像能力確認が失敗してもクラウドへ戻らないこと、画像エンコーダーがGPU/CPUモードともCPUで動くことを確認した。能力/MCPとリアクションのオフライン結合チェックも成功した。

常設8094へ1024×1024の合成図形PNGを送信し、ヘッダー`X-Ciel-Image-Max-Edge=256`・画像数1、赤丸・青四角の正解を確認した。応答完了3.154秒、入力128トークン・出力34トークン、キャッシュ0。同じ図形・質問を前処理なし1024pxで実行した隔離試験は入力1088トークンだった。単発確認であり、すべての画像の遅延や精度へ一般化しない。

開発側の新規LiveKitルームで、初回あいさつの後、人の文字・音声発言を送らずに1024px画像を`ciel.image`へ添付した。image.stateのreceived、赤と青の図形に触れた返答、音声フレームの受信を確認した。添付から返答テキストストリーム完了と音声受信の両条件成立まで17.436秒。API単体時間や音声開始遅延とは異なる。説明文の生成完了、修正版agentのエラーログ0、試験ルームの削除も確認した。人のマイク、Unityのファイル選択UI・端末スピーカー、写真・OCR・ゲーム画像の品質や連続会話負荷は未確認。

共有LLMと本番・開発agentだけを再作成した。LLMのDocker healthcheckも8094へ修正されhealthyで、各更新コンテナの再起動回数は0。推論コード・設定はサーバーの`~/work/ciel-deploy-backups/vision-20261110T011403Z/`にバックアップし、`deployment.json`が初回API反映、`api-image.json`が前処理試験、`live-image-check.json`が修正後の添付試験、`final.json`が最終状態の根拠。agent修正のバックアップは同フォルダ`agent-fix-f2028e830c275d9fd6b84bd2f6177323c1255351/`。初回の失敗ログはprivateな`live-image-agent.log`、修正後は`fixed-live-image-agent.log`として区別する。設定とDBバックアップは秘密を含むためGitへ入れない。

秘密のない確認JSONを`.local/vision-validation/constant-api-20261110/`へ回収した。実行用補助ファイルは`.local/local-vision-deploy/`。通常の送信画像と前処理画像はAPIや会話ホストが永続化せず、これらのファイルは合成試験だけの記録。
