# 手本のリグの解析：公式サンプル「桃瀬ひより PRO」とシエルの比較（2026-10-11）

計画書 `ciel-live2d-rebuild-analysis-plan-ja.md` の段階 1。サンプルは `.local/reference-rigs/`（利用規約により再配布できないので Git 管理外）。ここには、構造と動きの量の**数値の要約**だけを書く（絵・データは載せない、流用しない）。

## 1. 道具
| スクリプト | 役割 |
| --- | --- |
| `scripts/live2d/cubism_core.py` | Unity SDK の `Live2DCubismCore.dll` を Python から呼ぶ。書き出したモデルに値を与え、Cubism と同じ計算で頂点・不透明度・描画順を得る |
| `scripts/live2d/render-moc.py` | その結果を画像に描く（全身 1 枚 2〜3 秒）。Unity の描画と形が一致することを確認済み。クリッピングの縁に小さな点が出る差が残る |
| `scripts/live2d/analyze-rig.py` | `.cmo3` からデフォーマの木、`.moc3` から角度X・Y ±30 での各メッシュの動き（頭の幅で割った比）を表にする |

実行例：
```
python -I scripts/live2d/analyze-rig.py <.cmo3> <.model3.json> 出力.md <輪郭のメッシュID>
python -I scripts/live2d/render-moc.py <.model3.json> 出力.png --scale 0.5 --crop x0,y0,x1,y1 "ParamAngleX=30;ParamAngleY=30"
```

## 3. ひよりのデフォーマの木（頭まわり、要約）
```
体の曲面Z（ParamBodyAngleZ）
 └ 体の曲面Y（BodyAngleY）
    └ 呼吸（Breath）
       ├ 体・襟・リボンの曲面（BodyAngleX）…体の部位ごと
       └ 首の位置［回転］（BodyAngleX）
          ├ 首の曲面（AngleZ）── 首
          └ 顔の回転［回転］（AngleZ）
             ├ 顔の曲面（AngleX×AngleY）── 輪郭
             │   └ 髪影の曲面（X×Y）└ 髪影の揺れ（HairFront）
             ├ 左目の曲面／右目の曲面（X×Y）── まつげ・白目・二重など 13 枚
             │   └ 目玉の位置（EyeBallX×Y）── 瞳・ハイライト
             ├ 左頬／右頬の曲面（X×Y）── 頬の線・照れ・ハイライト
             ├ 左まゆ毛／右まゆ毛の曲面（X×Y）└ 位置（BrowY×X）└ 角度（BrowAngle）
             ├ 口の曲面（X×Y）── 唇・上口・下口・口中など 6 枚
             ├ 左耳／右耳の曲面（X×Y）
             ├ 前髪の曲面（X×Y）└ 前髪の曲面Z（AngleZ）└ 前髪の揺れ（HairFront）
             ├ 後ろ髪の曲面（X×Y）└ 後ろ髪の曲面Z └ 後ろ髪の揺れ（HairBack）
             ├ アホ毛の曲面（X×Y）
             └ 鼻（顔の回転に直接）、サイドアップ（毛束を 7 段の回転デフォーマの鎖で揺らす）
```
要点：
- **顔の回転（角度Z、回転デフォーマ）の下に、部位ごとのワープ（角度X×Y の 3×3 キー）を並べる**。部位どうしは親子にしない（兄弟）ので、部位ごとに別の量で動かせる。
- 揺れ（物理演算の出力）は、向きのワープの**子**のワープで受ける（向き → 傾き Z → 揺れ、の 3 段）。
- 長い毛束は、回転デフォーマを 7 段つないだ鎖（スキニング）で揺らす。
- 格子は小さく（5×5）、部位ごとに小さな範囲を覆う。
- 首は、首の位置（回転）の下で、顔の回転とは別に動く。

## 4. 動きの量（角度 ±30、輪郭の横幅 532 px を 1 とした比）
| 部位 | ひより X+30 の横の動き | ひより Y+30 の縦の動き | シエル（現行）X+30 | シエル Y+30 |
| --- | --- | --- | --- | --- |
| 輪郭（顔の肌） | +0.045（幅 ×0.95） | −0.030 | +0.202（幅 ×1.11） | −0.201 |
| 目（白目・瞳） | +0.055〜0.065 | −0.047〜−0.051 | +0.21〜0.31 | −0.28〜−0.29 |
| 眉 | +0.066〜0.082 | −0.050 | +0.177 | −0.235 |
| 鼻 | +0.110 | −0.067 | +0.338 | −0.377 |
| 口 | +0.080 | −0.057 | +0.288 | −0.341 |
| 前髪 | +0.035〜0.050 | −0.029〜−0.047 | +0.219 | −0.205 |
| 耳 | +0.007 | −0.030 | +0.11〜0.29 | −0.14 |
| 横の毛束（サイドアップ） | −0.01〜−0.02（**逆向き**） | −0.005〜−0.04 | 右 +0.165、左 −0.043（左右で非対称） | −0.03 |
| 後ろ髪 | −0.004（**逆向き**） | −0.027 | −0.040 | +0.007 |

読み取れること：
1. **ひよりの顔の動きは小さい**：輪郭は頭の幅の 4.5%、目は 6% ほど。見た目では 15〜20° の向き。シエルは 4〜7 倍動かしている。
2. **奥行きの順に動きが大きい**：後ろ髪・横の毛束（逆向き）＜ 耳（ほぼ 0）＜ 輪郭・前髪（4〜5%）＜ 目（6%）＜ 眉・口（8%）＜ 鼻（11%）。これが視差。前髪は輪郭とほぼ同じ量。
3. **横幅の変化**：向いた側と反対の目は幅 ×0.75〜0.9、向いた側は ×1.05〜1.28。輪郭は全体で ×0.95。
4. **描画順は向きで変えていない**（この範囲では、切り替えなしで成り立つ）。
5. 上下（Y）は、横（X）より小さい（輪郭 3%、鼻 7%）。下向きの方が小さい部位が多い。

## 5. シエルの設計への反映（`ciel-live2d-rig-design-ja.md`）
- デフォーマの木は 3 章の形にする。
- 動きの量は、4 章のひよりの比率を初期値にする（第 1 段階）。シエルの顔立ち（大きな目、耳が頭の上）に合わせて、見た目で調整する。
- 犬耳は頭の上にあるので、ひよりの横の耳（ほぼ動かない）とは違う。頭頂の髪と同じ奥行き（輪郭の 0.5〜0.8 倍程度）から始める。
