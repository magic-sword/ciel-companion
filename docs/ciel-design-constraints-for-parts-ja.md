# 素材作成に関わるキャラクター設計の要点（シエル）

出典：別リポジトリ `magic-sword/ciel-anime-design` の「キャラクター設定資料_主人公_シエル.md」（決定稿 Ver. 2.0、最終更新 2026-09-11）。このファイルは、パーツ素材を作る・生成に依頼するときに必要な部分だけを抜き出した要約。原文は上記リポジトリが正。

## 外見の要点
- モチーフは**サモエド型ヒューマノイド**。耳は**犬耳**（サモエドの立ち耳）。猫耳ではない。
  - 先端がほんのり丸みを帯びた、厚みと毛量のある三角形の直立耳。内側は、もこもこの毛（スマート・ナノファー）。
  - 頭部側面に「シームレスに結合」されている。顔の横に人間の耳はない。
  - 感情で動く（後ろに倒れる「ヒコーキ耳」、ピン立ち、片耳ピコピコ）。→ 耳の付け根と、耳の裏側の絵が要る。
- 髪：純白（シルヴァーホワイト）のロングウェーブ。前髪は瞳の上で整う。背中の中程まで波打つ。頭頂にアホ毛。
- 肌：**顔も含めた全身が均一な純白の白磁**。人間の血色感は排する。頬の血色（桜色）は、感情で灯る**インジケーター**で、常時はない。→ 頬の赤みは、別レイヤー（N）で、通常は薄く／消せる形にする。
- 顔：サモエドスマイル（口角が黒く、キュッと上がる）。漆黒の小さな鼻先。笑うと小さな八重歯が見える。
- 首：発光チョーカー＋ふわふわの毛皮の襟（カニス・カラー）。**首輪は首の前に重なる**（重なり順：首 → 首輪）。
- 服：ショート丈の純白パフジャケット（もこもこラフファー襟）。シアンブルー（瞳・LED・宝石）とチャコールブラック（スカート・バックル）。
- 尾：背中側の大きな巻き尾（今の上半身の素材には含まれない）。

## 色の基準
- 全身の肌・アウター・被毛：ポーセリンホワイト（超マット）。瞳・LED・宝石：シアンブルー（ハイグロス）。金具・スカート：チャコールブラック。
- 肌は、陶器の白。ベージュ・黄み・桃色を足さない。

## 素材作成への反映
- 耳の素材（外側・内側の毛・裏側・付け根）は、すべて**犬耳**として描く。
- 顔の側面に耳のレイヤーは不要。こめかみ・頬の外側は、髪と直接接する。
- 首輪（Neck_Gear）は、首の素肌（A2）より**上**に重ねる。
- 頬の赤みは、常時の絵ではなく、重ねるレイヤー（感情で変える）にする。
