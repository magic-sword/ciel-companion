# シエルのLive2D制作仕様

> 責務：外観と素材の制約、正式成果物、採用・組み込みの受け入れ条件。

この資料は外観、制作物の採用条件、素材の扱い、Unityへ納める条件を所有する。現行のファイル・層数・ハッシュは[素材一覧](../../../assets/ciel/current/README.md)と`approved.json`、作業手順とパラメーターは[リグ設計](ciel-live2d-rig-design-ja.md)、参考モデルの根拠は[参考解析](ciel-live2d-reference-rig-analysis-ja.md)を参照する。

## 現在の採用物と範囲

正式な編集対象は`assets/ciel/rig/ciel.cmo3`。素材は`assets/ciel/current/layers.json`、採用状態は`approved.json`、配布パッケージは`assets/ciel/runtime/manifest.json`が正本。現在の素材は115層、通常を含む11表情。身体・上着・左右の手・尻尾・ほっぺの変形まで採用物に含まれる。初期試作の「4表情」「衣装・尻尾は対象外」「素材分割中」を現状として使わない。

アプリは顔中心の上半身表示を基本とし、再生音声の口パク、まばたき、視線、表情、耳・髪等の揺れ、接触への反応を組み合わせる。大きな肘曲げ・腕上げと衣服の物理出力接続等の未完了事項は採用済みと混ぜず、[配布モデル](../../../assets/ciel/runtime/README.md)と[確認状況](../../testing/verification-status-ja.md)で管理する。

## 外観の制約

- サモエド型ヒューマノイド。白〜銀白の髪、犬の立ち耳、アホ毛、シアンの瞳。人間の耳を追加しない。
- 鼻は採用原画の控えめな線・陰影を守り、黒い犬型の鼻先へ変更しない。
- 肌は滑らかな白磁の白。露出部で質感を統一し、人間らしいベージュ・桃色や常時の頬紅を加えない。感情による赤みは独立した制御とする。
- 白いパフジャケット・毛皮の襟・シアンのチョーカーと胸の飾り等は、正式素材とユーザー提供の外観参考から引き継ぐ。首輪は首の手前。
- 承認画像・モデルを元に変更し、文章だけから顔立ちを作り直さない。部位追加では既存の縮尺・線・色・描画順と合わせる。

素材を新規生成するときも、画像生成が必要な部分と既存素材の加工を区別する。輪郭や目を症状ごとに継ぎ足して直す前に、部位の分離、隠れ領域、親子関係を確認する。制作担当のAI名ではなく、原画・分割・Cubism・書き出し・採用それぞれの成果物と確認条件で作業を依頼する。

## 素材とリポジトリの責務

| 場所 | 置くもの |
|---|---|
| `assets/ciel/current/` | 正式素材、配置manifest、採用モデルのハッシュ |
| `assets/ciel/rig/` | 正式な編集モデル、表情、現行の確認図 |
| `assets/ciel/runtime/` | Unityへ更新するSDK一式とmanifest |
| `unity/Assets/Characters/Ciel/` | アプリで使う採用済み書き出し |
| `.local/` | 編集候補、比較画像、途中のモデル、再生成できる中間物 |

正式な編集モデル・原画・素材と再開に必要な生成不能物はGit/LFSへ置く。PSD/XCF等、manifestから再生成できる中間物はGit対象外。世代別の候補フォルダ・旧版の確認図を現在のツリーへ増やさず、履歴はGitから参照する。層数やアトラス構成を説明文へ複製し続けず、正式manifestを更新する。

参考サンプルの画像・モデルを再配布したり流用したりしない。コードのライセンスがキャラクター・原画・声・モデルへ自動で適用されることはない。[第三者依存](../../project/third-party-dependencies.md)と元の利用条件を確認する。個人管理の設定資料・参照音声を無断で公開資料へコピーしない。

## 変更と受け入れ

1. `approved.json`と一致する正式モデルから候補を作り、変更部位・維持する見た目・試すパラメーターを明確にする。
2. 正面だけでなく顔X/Y/Z端点、X×Y、視線、瞬き、口0/中間/全開、表情の組み合わせを確認する。参考解析の移動量は初期値であり合格値ではない。
3. 目・口の中身の漏れ、二重線、髪の穴、鼻・目への毛束の滑り込み、耳の根元、首と装飾の接触、白縁・塗り残しを黒白灰の背景で確認する。
4. 表情から通常への復帰、閉口、音声停止・割り込み・再接続、物理演算の跳ねを確認する。口パクは相手のマイクでなくシエルの実再生音声へ同期する。
5. SDK出力、素材・モデルのハッシュと確認図を一式で採用し、Unityの更新・参照・.metaを検証する。Editorの静止画だけでスマートフォンのfps合格としない。

具体的なコマンドと採用操作は[リグ設計](ciel-live2d-rig-design-ja.md)を参照。新しい課題は該当仕様へ書き、過去の試行記録を追記しない。
