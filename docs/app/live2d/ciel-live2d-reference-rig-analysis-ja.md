# 参考リグの構造と設計への利用

> 責務：参考サンプルの構造・数値と制作へ使う条件。現行モデルの台帳ではない。

この資料は公式サンプル「桃瀬ひより PRO」の解析値と、その数値を制作へ使う条件を説明する。シエルの現行層数・正式モデルの正本ではない。[制作仕様](ciel-live2d-production-spec-ja.md)と[リグ更新](ciel-live2d-rig-design-ja.md)を参照する。

参考モデルは利用条件に従い`.local/reference-rigs/`へ保持する。画像・データをGitへ転載・流用せず、ここには構造と数値の要約だけを置く。異なるサンプルを解析した場合は対象・条件を明記してこの資料を更新する。

## 解析方法

`scripts/live2d/cubism_core.py`でCoreの頂点・不透明度・描画順を取得し、`render-moc.py`で確認する。計測の座標系、パラメーター値、基準幅を揃える。CoreとUnityの最終画面の一致は別に検証する。

ひよりPROの解析対象はアートメッシュ140、ワープ50、回転54、グルー26、パラメーター70。ワープ格子は5×5。これは参考モデルの構成であり、シエルへ同じ個数を要求しない。

## ひよりのデフォーマの木（頭まわり、要約）
```
体の曲面Z（ParamBodyAngleZ）
 └ 体の曲面Y（BodyAngleY）
    └ 呼吸（Breath）
       ├ 体・襟・リボンの曲面（BodyAngleX）…体の部位ごと
       └ 首の位置［回転］（BodyAngleX）
          ├ 首の曲面（AngleZ）── 首
          └ 顔の回転［回転］（AngleZ）
             ├ 顔の曲面（AngleX×AngleY）── 輪郭
             │   └ 髪影の曲面（X×Y）└ 髪影の揺れ（HairFront）
             ├ 左目の曲面／右目の曲面（X×Y）── まつげ・白目・二重など 13 枚
             │   └ 目玉の位置（EyeBallX×Y）── 瞳・ハイライト
             ├ 左頬／右頬の曲面（X×Y）── 頬の線・照れ・ハイライト
             ├ 左まゆ毛／右まゆ毛の曲面（X×Y）└ 位置（BrowY×X）└ 角度（BrowAngle）
             ├ 口の曲面（X×Y）── 唇・上口・下口・口中など 6 枚
             ├ 左耳／右耳の曲面（X×Y）
             ├ 前髪の曲面（X×Y）└ 前髪の曲面Z（AngleZ）└ 前髪の揺れ（HairFront）
             ├ 後ろ髪の曲面（X×Y）└ 後ろ髪の曲面Z └ 後ろ髪の揺れ（HairBack）
             ├ アホ毛の曲面（X×Y）
             └ 鼻（顔の回転に直接）、サイドアップ（毛束を 7 段の回転デフォーマの鎖で揺らす）
```
要点：
- **顔の回転（角度Z、回転デフォーマ）の下に、部位ごとのワープ（角度X×Y の 3×3 キー）を並べる**。部位どうしは親子にしない（兄弟）ので、部位ごとに別の量で動かせる。
- 揺れ（物理演算の出力）は、向きのワープの**子**のワープで受ける（向き → 傾き Z → 揺れ、の 3 段）。
- 長い毛束は、回転デフォーマを 7 段つないだ鎖（スキニング）で揺らす。
- 格子は小さく（5×5）、部位ごとに小さな範囲を覆う。
- 首は、首の位置（回転）の下で、顔の回転とは別に動く。


## 視差の参考値

角度±30、輪郭幅532pxを1とした解析値。X+30の横移動は輪郭約+0.045、目+0.055〜0.065、眉+0.066〜0.082、鼻+0.110、口+0.080、前髪+0.035〜0.050。横の毛束・後ろ髪には小さい逆向きの動きがある。Y+30では輪郭約−0.030、目約−0.05、鼻約−0.067、口約−0.057。

奥行きによる移動量の差、目の幅の変化、首と顔の分離を観察する材料とする。旧試作との倍率比較や旧シエルの層数を現行値として残さない。シエルの大きい目・髪・耳に適した量は、同じ背景・画角での端点と連続動作の確認で決める。
