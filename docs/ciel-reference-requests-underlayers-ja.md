## 1. なぜ必要か（何が新しく見えるか）

頭を「円柱の前面に、逆さのホームベース形の顔の板がついた形」として回すと、正面では隠れていた次の面が見えます。いまの絵は正面だけなので、そこが空いたり、髪の色が透けたりします。

| 見えるようになる部分 | いつ | いまの状態 |
| --- | --- | --- |
| 顎の裏、のどの前面 | 上を向く（角度Y＋） | 空く。体のレイヤーの首の上端で切れて見える |
| 顔の側面（頬・こめかみ・顎の側面） | 左右を向く（角度X±） | 正面の肌を引き伸ばしているだけで、側面の陰影がない |
| 頭頂部の髪、額の上 | 下を向く（角度Y−） | 前髪が下がって、後ろ髪の上端が見える |
| 耳の裏側 | 左右を向く | 耳は、平らなカードとして動かしているだけ |

## 2. 依頼する画像

共通の条件
- **肌の材質・色の最優先基準（2026-10-09追記）**：`assets/ciel/generated/upper-body-1x.png` を基準にする。このキャラクターは人間ではなく、陶器のように滑らかな白い外装肌のヒューマノイドロボット。人間の肌に見えるベージュ・黄み・桃色・血色を加えない。明部は原画のほぼ白い色、陰影は原画の低彩度の灰紫を維持する。単なる白飛びや金属光沢にはしない。顔・顎・首・肩で同じ材質を保つ。旧お手本に含まれる強い赤みを色見本にしない。
- **Cの現行仕様**：目・眉・鼻・口・鼻の点・頬の赤み・内部線を描かない。滑らかな白い肌面と外周のみ。下記の古いひな形と矛盾する場合はこの条件を優先する。肌色修正版は下レイヤーの `_v3.png`、角度見本は `_porcelain.png` を参照する。
- **大きさと位置**：1536×1536。`assets/ciel/requests/face-hair-crop-1536x1536_x318_y236.png`（正面）と同じ切り抜きの枠で、同じ向きの見本（`assets/ciel/generated/pose-ref/` の同じ名前の画像）と、頭の位置・大きさがそろうこと。
- **背景**：透明（PNG）。難しいときは、真っ白にして知らせる。
- **絵柄**：元の見本と同じ（目・髪・肌の色・陰影、線の太さ）。デザインを変えない。
- **描くもの以外**：描かない（透明にする）。

優先順位が高い順です。

## 3. 受け取ったときに、こちらで確認すること

- 見本と、顔の輪郭・顎の線・首の幅が重なるか（差の画像で確かめる）。
- 肌の色と陰影が、正面の絵とつながるか。
- 透明の範囲が正しいか（描かないはずの髪や服が残っていないか）。

## 4. 補足

- 最初は、K-3 と S-L・S-R の 3 枚で、効果を確かめるのがおすすめです。
- 左右を向く側面は、向きによって形が変わるので、まず ±30° の 2 枚で始め、足りなければ ±15° を足します。
- 画像全体が描き直されるので、見本と少しずれることがあります。そのときは、こちらで位置を合わせて使います。

## 5. 追記（2026-10-09）：頬のもちもち感のための素材

試した結果（仕様書 12.34）：頬の輪郭を、形の変形で広げても、**広げた先に肌の絵がない**ので、見た目が変わらない。見本のもちもち感は、髪の下から丸い頬が覗く形で出ている。以下を追加で依頼する。

### C：髪の下まで続く素肌（優先度：高。S の依頼と一緒に頼むとよい）

| 画像 | 内容 | 参考にする見本 |
| --- | --- | --- |

| C-L30、C-R30 | 左右 30°。同じく素肌だけ。向いた側の頬が丸く盛り上がる輪郭、奥側の頬のカーブも描く | `pose_xL30_y0.png`、`pose_xR30_y0.png` |

文面のひな形

> 添付の画像と全く同じ姿勢・位置・大きさ（1536×1536）で、「顔の素肌」だけを描いてください。
> - 描く：額、こめかみ、頬、顎。髪で隠れている所は、頬が丸く、ふっくら（もちもち）見えるように、自然に描き足す。目・鼻・口は、元のとおり残す。
> - 描かない（透明にする）：髪、猫耳、首、首輪、体、服、背景。
> - 肌の色と陰影は、元と同じ。輪郭は、丸く柔らかい線にする。
> - 背景は透明の PNG。

使い方：Face_Skin を、これに置き換える（髪の下の肌が、向きとともに、顔の輪郭として現れる）。S（側面）の依頼と、役割が重なるので、**S を C に統合してよい**。
