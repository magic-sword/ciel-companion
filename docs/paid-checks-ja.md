# 外部APIを呼ぶ試験

> 責務：外部APIを呼ぶ試験、費用と実行範囲の確認方法。

通常回帰は[回帰テスト](regression-tests-ja.md)を使い、資格情報を渡さずに実行する。ここでは、実モデル・LiveKit・読み上げ等を呼ぶ評価の選択と費用の確認を扱う。

## 選択と実行範囲

試験の登録は`server/agent/paid_checks.toml`、モデル・役目と使用量の記録は`models.py`・`usage.py`が正本。変更した処理に関係する試験だけを選び、過去の全評価を修正のたびに回さない。

```sh
python scripts/server/paid-checks.py
python scripts/server/paid-checks.py --since <commit>
python scripts/server/paid-checks.py --all
```

これらは候補を表示し、試験を実行しない。実際に回すときは対象、backend、採点モデル、試行数、上限を確認する。ローカルLLMを評価対象にしても、採点器・音声認識・検索等がクラウドを呼ぶ場合がある。OpenAIクレジットを使わない試験では、採点を含む全経路がローカルかモックであることを確認する。

同じ失敗を条件を変えず繰り返さず、小さい単発確認から原因を切り分ける。反復する前に1回あたりの見込みと回数を利用者へ伝える。Minecraftは[専用ベンチマーク](minecraft-benchmark-ja.md)の有料指定・予算を使う。

## 料金の記録

公式の現行料金と、実行したモデル・入力/出力/キャッシュ/音声の使用量から見積もる。登録簿やコードにある既存の概算は課金上限や最新料金の保証ではない。通貨換算・過去の1日料金を現在の相場として転載しない。使用量が取得できなかった値は0円でなく未取得とする。

結果のモデル・条件・データの場所・未確認範囲は[確認状況](verification-status-ja.md)を更新する。本文・音声・資格情報を公開ログへ入れず、料金確認のために実行範囲を拡大しない。
