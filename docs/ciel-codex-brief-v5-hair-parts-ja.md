# Codex への依頼：髪と顔のパーツ分けの作り直し（v5）

背景：今のパーツは、前髪と横髪が 1 枚、横髪の長い毛束は後ろ髪や体に焼き込み、顔の肌に前髪の毛先の線が焼き込み、頭頂の髪が無い、という粗い分け方で、頭の向きを変えると継ぎ目や下のレイヤーが見える。編集では限界があるので、パーツを分けて再生成する。
根拠：`docs/ciel-live2d-material-guidelines-research-ja.md`（切り分けの指針）、`docs/ciel-design-constraints-for-parts-ja.md`（キャラクター設計）、`docs/ciel-angle-y-research-ja.md`（上向き・下向きの見え方）。

進め方：Claude Code が `scripts/codex/run-codex.ps1` で Codex（`codex exec`）に依頼し、結果を確かめて次へ進める。区切りごとにユーザーが確認する。進み具合は「6. 進捗」に書く。

## 1. 方針（2026-10-10 改訂：ピクセル一致をやめる）
- 生成した絵は、元画像とピクセル単位では一致しない（位置・毛先の形・線が少しずつ違う）。それを前提にする。
- 目標は「**組み上げたときに、継ぎ目が見えず、元画像と同じキャラクターに見える**」こと。元画像との差（数 px のずれ、毛先の形の違い）は問題にしない。
- そのための作り方：
  1. **継ぎ目を、隠れる場所に置く**：パーツの境目は、上のパーツの下に入る位置（前髪の付け根は頭頂の髪の下、横髪の付け根は前髪の下、など）に置く。見える場所で、2 つのパーツの絵をつなぎ合わせない。
  2. **下のパーツは大きく描く**：上のパーツに隠れる側を、たっぷり（60px 以上）描き足す。上のパーツの形が少しずれても、下のパーツの絵が隙間を埋める。
  3. **パーツは単独で完成した絵にする**：各パーツは、それだけで見ても自然な形（毛先まで描いた毛束、縁のなめらかな肌）にする。別のパーツの切れ端や、切り抜いた跡を残さない。
  4. **色・線をそろえる**：髪の色、線の色・太さ、肌の色は、パーツ間で同じにする（基準から採取）。継ぎ目が目立つ一番の原因は、パーツ間の色と線の違い。
- 合格の判断：パーツを重なり順に重ねた図と、元画像を並べて、(a) 継ぎ目・隙間・切れ端が見えない、(b) 同じキャラクターに見える（髪型・毛量・色）、(c) 各パーツを少し動かしても（±20px、±5°）隙間が出ない。ピクセル単位の位置の誤差は測らなくてよい（参考に出すのはかまわない）。

## 2. キャラクターと守ること
- シエルは、**サモエド犬がモチーフのヒューマノイド**。白銀の長い髪（ふんわり波打つ、羽毛のような毛先）、頭頂にアホ毛、頭の上に**サモエドの立ち耳（犬耳）**。顔の横に人間の耳はない。肌は**全身が均一な白磁（陶器のような白）**で、人間の血色を足さない。瞳はシアンブルー。詳細は `docs/ciel-design-constraints-for-parts-ja.md`。
- 既存ファイルは、変更・上書き・削除しない。新しいファイルは `assets/ciel/generated/v5/` にだけ書く（完成は `v5/parts/`、作業用は `v5/_work/`、不採用は `v5/_rejected/`）。
- 作業用の大きな画面（マスター）は **2172×2896**（`assets/ciel/layers/*/*.png` と同じ座標）。基準は `assets/ciel/generated/upper-body-2x-firefly-black.jpg`（2 倍の基準画像）と `upper-body-1x.png`（1086×1448）。
- 画像生成の出力は 1254×1254 が上限、位置・縮尺は保証されない、参照付きの編集は対象外の輪郭も変わる。だから、生成は「形と描き込み」に使い、パーツごとに狭い範囲を切り出して生成し、置く位置はスクリプトで合わせる。長い髪は、重なる区画に分けて生成して合成してよい（区画の継ぎ目も、上の 1 の考え方で目立たなくする）。
- 生成回数：1 パーツ 6 回まで。後ろ髪は 10 回、横髪は左右それぞれ 6 回。足りなければ止まって相談する。
- 確認できなかったことは「未確認」と書く。

## 4. 各パーツの手順
1. 切り分け図・マスク（`v5/_work/masks/`）の範囲を使う。範囲を切り出した基準画像と、範囲のガイド画像を参照に渡して生成する。
2. スクリプトで置く位置を合わせ、マスター座標の `v5/parts/名前.png` にする。採用はマスク（見える範囲＋描き足す範囲）の内側だけ。縁は 1〜2px なめらかにし、白い縁を残さない。
3. 確認（画像で）：(a) 単独で黒・灰の背景に置いた図（切れ端・穴・白い縁が無いか）、(b) それまでのパーツと重なり順に重ねた図と、元画像を並べた図（継ぎ目・隙間が無いか、同じキャラクターに見えるか）、(c) そのパーツを ±20px ずらした図（隙間が出ないか）。
4. 報告：出力ファイル、生成の回数、(a)〜(c) の結果、気づいた問題（形が元と違う所、描き足しが推測の所）。

## 5. 順番
前髪（段階 2 で作成済み。新しい方針で採用）→ 頭頂の髪 → 横髪（左右）→ 後ろ髪 → 体 → 顔の肌 → 眉 → アホ毛 → 頬の赤み → 鼻。最後に全部を重ねた図（`v5/_work/stack.png`）と、元画像を並べた図。

## こちら側のメモ（Codex には渡さない）
- 受け取ったパーツの組み込み（.cmo3 のメッシュの追加、Head_Warp の子にする、描画順、角度Y で頭頂の髪を見せる、など）は、Claude Code が行う。新しいメッシュ（横髪・頭頂の髪・アホ毛・頬の赤み・鼻・眉）が増えるので、Cubism で PSD から取り込むか、既存の未使用メッシュを作り変える。
- 顎の線のレイヤー（`face-skin-from-a2.py` が作る `Face_Base.png`）の考え方は、新しい Face_Skin にも使う（顎の線は Face_Skin から抜いて、別のレイヤーで上向きに消す）。
