# 上向き・下向き（角度Y）の見え方の調査と、直し方の案（2026-10-10）

## 1. お手本と今の描画の違い（`pose-ref/pose_x0_y{U30,U15,D15,D30}_porcelain.png` と Unity の描画）
| 向き | お手本 | 今のモデル |
| --- | --- | --- |
| 上向き | 顎の輪郭線が**ほぼ無い**。顎の下の面が、明るい肌の**なだらかな陰影**で、首へそのままつながる。首が長く見え、明るい | 顎の線（濃い紫灰）が残る。首は**暗い灰紫の平らな柱**で、顎との境がはっきりしている |
| 下向き | 顔は**縦に縮み**、目は下がるが、顔の下半分は首輪の後ろへ隠れる。**頭頂の髪のボリューム**が大きく見える。前髪が目にかかる | 顔全体が下へずれて、画面の下で切れる。頭の上が平たくつぶれる。目が大きいまま |

## 2. Web で調べた一般的な手法
- **上向きで顎の線を消す**：輪郭の「線」と「塗り」を別のパーツにし、角度Y で線を消す。方法は 3 つ。
  1. マスクの反転：不透明度 0 のマスク用パーツを線にクリッピングし、マスクを反転。上向きのキーで、マスクを線に重ねて線を隠す（[cgbox](https://cgbox.jp/2020/12/21/live2d-up-rinnkaku/)）。
  2. 背面法：線のパーツを、角度Y のキーで、塗りの後ろへ引っ込める（[ゾンビうつけくん](https://note.com/zombiefff/n/nbc389edd03f0)、[YouTube](https://www.youtube.com/watch?v=_l9OkLzkERo)）。
  3. 線のパーツの不透明度を、角度Y で 1→0 にする（最も簡単。上の方法の代わりとして、一般的な考え方）。
- **顎と首をなじませる**：顎の下・首の影の色を合わせる。顎下の影のパーツを上に重ね、正面では不透明度 0、上向きで 100% にすると奥行きが出る（cgbox）。上向き（30）では、顔の下の影の幅を少し広げて顎下を表す（[伊糖だねこ](https://note.com/itodaneko/n/n966f2208b4a4)）。顎のラインの素材を用意して、上下左右で見せる（[kawase](https://x.com/kawase1234567/status/1795685278616883359)）。
- **下向き**：顔の縦幅を少し狭める。輪郭は、顔周りの影がほぼ見えなくなる程度に（[伊糖だねこ](https://note.com/itodaneko/n/n966f2208b4a4)）。前髪は下を向くと垂れ、目に近づく。前髪の上部や後頭部を縮めすぎない。頭蓋骨の丸みを意識する（[saraemi](https://saraemi.com/vtuber/2021/10/20/live2d_face_y/)、[乾物ひもの③](https://note.com/himono_vtuber/n/ne6f7c0fdfdaa)）。つむじが見える絵では、下を向くと隙間が開くので、影のパーツを足す（乾物ひもの③）。後ろ髪は、上部だけ動かし、下部は重力でそのまま垂らす（乾物ひもの③）。
- **特定の角度だけ形を直す**：ブレンドシェイプで、特定の角度でだけ効く補正を作る（[伊糖だねこ⑦](https://note.com/itodaneko/n/ndbaa6da2927f?hl=en)）。

## 3. このモデルへの当てはめ（案）
### 上向き
1. **顎の線を別のレイヤーにして、角度Y で消す**：A2 の顎・頬の線だけを取り出した画像（線レイヤー）を作り、Face_Skin からは線を抜く。線レイヤーは、上向き（Y＋）で不透明度 1→0。正面と下向きでは今と同じ。
2. **顎の下の面を、明るい肌のなだらかな陰影にする**：首の柱（Body_Base）の色を、暗い灰紫の一色から、顎の直下だけ淡い影で、下へ向かって明るい肌になるグラデーションへ。お手本の上向きの首の明るさに合わせる。
3. （必要なら）顎下の影のパーツ：顔と一緒に動き、上向きでだけ現れる、淡い影。

### 下向き
4. **頭の 3D モデル（`head3d-keys.py`）の下向きの動きを、お手本に合わせて測り直す**：目の位置・顔の縦の縮み・顎の隠れ方を、お手本と重ねて合わせる（`preview-vs-ref.py`）。今は、顔が下へずれすぎ、縦に縮まない。
5. **頭頂の髪**：下を向くと見える頭頂の髪（H-2・H-3）を、前髪の下に敷く。H は粗いので、作り直しが要るかもしれない。

## 4. 素材が要るか
- 1・2・3：手元の A2 からスクリプトで作れる。素材の追加は不要。
- 5：頭頂の髪は、既存の H-2・H-3 を試し、粗さが目立てば、Codex に作り直しを頼む（犬耳の付け根と一緒に）。
