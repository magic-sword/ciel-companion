# シエルとその人との関係の決定記録

日付：2026-10-18（日本時間）。状態：試作。その人について覚えておくメモ（[決定記録](person-notes-ja.md)）の上に作る。

## 決めたこと

| 項目 | 決定 | 理由 |
|---|---|---|
| 何を持つか | 1 人 1 行（`person_relationship`）。**親しさの段階**（0 はじめまして・1 顔なじみ・2 仲良し・3 大切な人）、**シエルの気持ち**（一人称の 2〜3 文）、**一時的な気分**（ちょっと拗ねている、など。たいていは空） | メモは「その人について知っていること」、関係は「シエルがその人をどう思っているか」。分けて持つと、話し方の下敷きにしやすい。段階は話し方を変える目安、気持ちの文は細かな温度を伝える |
| 下がるか | 段階は下げない。下がるのは一時的な気分だけ（拗ね・寂しさ）。気分は次の会話で書き直し、謝ってくれた・楽しく話せたら消える | 利用者の判断（2026-10-18、おすすめの形）。安心して使えるように。シエルはその人を嫌いにならない |
| 上がり方 | 1 回の会話で 1 段まで。しかも今の段階で「ちゃんと話した会話」（その人が 4 回以上話した会話）が 2・4・8 回になってから（`STAGE_UP_SESSIONS`）。その上で、文字のモデルが「距離がはっきり縮まった」と判断したときだけ | ちょっとした会話で急に親しくならないように。上げてよいかはコードで決め、モデルには上げるかだけ聞く |
| 初めて書くとき | 前からメモがある人は、メモと会話から 0〜2 を決める（3 にはしない） | すでに何度も話している人（博士さんなど）を「はじめまして」から始めると不自然なので |
| 寂しさ | 顔なじみ以上の人と 7 日以上会っていなければ、会えたときに「しばらく会えなくて、少し寂しかった」を添える（保存せず、前に話した日から計算） | 「しばらく話さないと少し寂しがる」を、記録を増やさずに出す |
| 誰が書くか・いつ | 会話が終わるとき 1 回だけ、メモを書き終えたあとで、会話の裏の文字のモデル（`CIEL_NOTES_MODEL`、既定 `gpt-5.4-mini`）が、今の関係・メモ・その会話の文字起こし（最後の 80 行）から書き直す（`relationship.py`、指示は `config/prompts/relationship.md`） | 関係はゆっくり変わるものなので、会話の途中で書き直さない。会話を止めない |
| 会話への渡し方 | 本人だと自信を持って分かったその会話の最初の発言に添える。**ひとり・身近な人**のときは段階・寂しさ・気分・気持ち（「シエルの心の中。そのまま口に出さない」と添える）。**人前**のときは段階だけ（「口調だけに表す」） | 人前で気持ちの中身を話すと、ほかの人に伝わるので |
| 話し方 | `speakers.md` に段階ごとの話し方（はじめまして：丁寧で少し緊張、顔なじみ：打ち解けた丁寧語、仲良し：ところどころくだけた言い方・軽い甘えやからかい、大切な人：気持ちを素直に言う）。気持ちの文は読み上げず、口調や反応の温かさににじませる。拗ねは会話の始めに [jitome]・[angry] で軽く、すぐ機嫌を直す | 関係を「説明する」のではなく、態度で感じてもらうため |
| 見せ方 | 画面には出さない（好感度のゲージなどは作らない） | 利用者の判断（2026-10-18）。数値が見えるとゲームっぽくなり、自然さが減るので |
| 同意・消去 | メモと同じ同意の範囲（声を覚えていて、お話を覚えることにも同意した人だけ）。声の記録を消すと関係も消える。「私のことどう思ってる？」には、届いている気持ちか `recall_about_speaker`（気持ちも一緒に返す）から答える。管理用に `speaker_admin.py relation <番号>` | その人の会話から作る、その人に結びついた情報なので |
| ログ | 段階の番号と会話の数だけ。気持ちの中身も会話も出さない | 仕様書 8 章 |

## 関係するファイル

## 確かめたこと（2026-10-18）

自宅サーバーで、本番の会話サーバーとは別のコンテナに今回のコードを置き、実際の文字のモデル（`gpt-5.4-mini`）・会話モデル（`gpt-realtime-2.1-mini`、文字だけ）・DB で試した。試験用の人は終了後に削除した（関係も一緒に消えることを確認）。

- 書き直し：
  - メモ 3 件（高校 3 年生、絵が好き、よく夜に話す）がある人の初回は段階 2（「よく夜に話す」から）。
  - ふつうの会話・回数が足りないときは上がらない。回数に達しても、天気の話だけなら上がらず、進路の打ち明け話では 1 段だけ上がった。
  - からかわれた会話で気分「ちょっとだけからかわれて、むくむくしているのです」。次の会話で謝られると気分が消えた。
  - 気持ちの文に「今日は」と書いて、次の会話でシエルが「今日は進路を決めたって聞いて」と今の話のように言ってしまった → 「いつ読んでも通じる書き方」と指示し、直った。
  - 気分がいつも何か書かれていた（「やさしい気持ちのままです」など）→ 「たいていは空」と指示し、拗ねたときだけ付くようになった。
- 会話への渡し方：ひとりのときは最初の発言にだけ段階・寂しさ・気分・気持ちが付く。人前では段階だけ。`recall` で気持ちも読める。
- シエルの返事（あいさつ 1 回ずつ、各 2〜3 回）：
  - 拗ねているとき「[jitome] えへ、前のお手の話、ちょっとだけ拗ねてたって覚えてるよ……でもいい笑い話にできるくらい、元気にお話ししたいな」のように、軽くかわいく出た。
  - 人前で「仲良し」とだけ渡すと、初めは「お名前と仲良しだって」と口に出した → 「親しさ：仲良し（口調だけに表す。口に出さない）」にして直り、「今夜はゆっくりお話ししようね」のように口調にだけ出た。
  - 寂しさは「久しぶりに声が聞けて、ワタシも心がぽかぽかしてます」のように、やわらかく出た（「寂しかった」とはっきり言わないこともある）。
  - まだ残る：気持ちの文に引っぱられて、あいさつで「そっと応援していくのです」のように気持ちをなぞることがある（3 回に 1 回くらい）。

## まだのこと

- 実際の声の会話で、何回も話して段階が上がっていくか、口調の変わり方が自然でかわいいか（試したのはあいさつ 1 回分の文字だけ）。
- 段階が上がる回数（2・4・8 回）が、ふだんの使い方で早すぎ・遅すぎないか。
