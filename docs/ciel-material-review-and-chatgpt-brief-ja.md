> **状況（2026-10-10 追記）**：2 章の 1（素肌ベース）・2（首）は、生成ではなくスクリプトで作った A2（`assets/ciel/generated/v4/`）と、`scripts/live2d/bake-neck-from-a2.py` で済んだ。C-L30・C-R30・K-2・K-3 は削除した。Unity で実際に見えていた不具合の多くは、素材ではなく、リグ・書き出し側だった（仕様書 12.39）。残りの素材（髪の分割、犬耳の裏・付け根、口の中、頬の赤みなど）を作るときに、この資料を使う。

## 0. 結論
1. 粗さの原因は、(a)低解像度の拡大、(b)隠れる面の描き足し不足、(c)向きごとに別々に描かれた絵の不一致、の3つ。(a)(b)は編集では直らず、**再生成が要る**。
2. 継ぎ目は、主に **「輪郭線の色が箇所によって違う」「肌の色が体と顔でつながっていない」「重なり幅が足りない」** から出る。
3. 現在の下レイヤー（C・K・N・H・E）は、「向きごとに、肌の板を1枚ずつ足す」方式。板が**単体で浮いた形**（顎の破片など）で、顔・首・体のどれともつながっていない。ここが、下レイヤーが剥き出しになる主因と考えられる。
4. 提案：向きごとの板をやめ、**「つながった1枚の大きい基準素材（頭・首・肩の素肌）を、はみ出すほど大きく描く」**方式を、正面で作る。向きの違いは、Live2D の変形で出す。向きごとの描き足しは、どうしても変形で出ない面（顎の裏、耳の裏、頭頂の髪）に限る。

## 3. 切り分けるべき素材
- 首：Body_Base から独立させる。
- 口の中：Mouth の3種（閉・小・大）のうち、開いた口は、**口腔（内側）と周囲の肌**を分ける。
- 髪：前髪／左右の横髪（体の前）／後ろ髪／アホ毛。いまは前髪が1枚。
- 毛皮の襟：胴体から分ける。裏側を描き足す。
- 虹彩のハイライト：虹彩の本体から分ける。
- 耳：外側の耳（毛）、内側の毛並み。耳の根元の房は、耳の側に。
- 頬の赤み：肌から分ける（N）。

## 4. 繋げておくべき素材（分けない）
- **顔の素肌＋顎＋のどは1枚の連続した絵にする**（いまの C と K に分かれている状態をやめる）。つなぎ目で色がずれるため。
- 耳の根元の房は、耳と一体（耳の下の髪と、別にしない）。
- 白目の左右の中の、まつ毛と二重は、状態（開・半・閉）ごとに一体（いまのまま）。
- 首輪とバックル・チャーム（Neck_Gear）は一体でよい。胸の宝石（Chest_Gem）と、ベルトは、体と動きが同じなら、体に焼き込んでよい。
- 髪のうち、同じ向きに同じだけ動く房は分けない（分けすぎない）。
- 目の中の瞳孔は、虹彩に含める。

## 5. 継ぎ目・色の違いの直し方
共通：色の基準は `upper-body-1x.png`。頬の明部 RGB 約 (252,249,250)、首の影 約 (220,207,220)（`ciel-reference-requests-underlayers-ja.md` の記載）。

| 症状 | 原因 | 直し方 |
| --- | --- | --- |
| 輪郭線の色が、箇所で違う（暖色／紫灰／青紫） | 生成のたびに線の色が変わる。コードで消している箇所もある | **線の色を3種類に固定し、すべて原画から採取する**：肌の外周（原画の顎の線は RGB 約 (117,102,120)・幅 約 3px）、髪の外周（青紫）、口・目の内側。原画と違う色の線は使わない（2026-10-10 訂正：当初の「茶色禁止」は広すぎた）。つなぎ合わせる側の縁は、**線を描かない**（内側は線なしの塗りだけにする） |
| 顔と首、首と体の肌の色が違う | 首が、ピンク寄りの灰色（K）で、体は白 | **顔→首→肩を、同じ肌のパレット（明部・中間・影の3色）で塗り直す**。つなぎ目は、**色を段階的に変えるグラデーション**（幅 30〜60px）にして、段差を作らない。影は、**顎の下からのど**にだけ入れ、体側では消す |
| つなぎ目の線が見える（パーツの端が平ら） | 端が、直線で切れている | **端を、隣のパーツの下に、80px以上潜らせる**。端の不透明度を、**内側 20〜40px で、0→1 に滑らかに**変える（羽根のように）。切り口を、**他のパーツの絵の下に隠す** |
| 下のレイヤーが、剥き出しになる | 重なり幅の不足、描き足し不足 | **ひとまわり大きく描く**（髪の根元・首の上端・頬の外側を、**20〜40px 大きく**）。重なり順は、**肌→首→体→髪→前髪** |
| 髪の周りの、白い切れ端・残留ピクセル | 低解像度の切り抜き | **2〜3倍の解像度で描き直す**。切り抜きの縁は、**アルファを、1〜2px、内側へ縮めてから、なめらかにする**。白い縁（フリンジ）は、**縁の色を、隣の色へ置き換える（デコンタミ）** |
| 毛皮・髪の縁がぎざぎざ | 低解像度を拡大した | 同上。再生成（2〜3倍）が正。手直しでは、**ぎざぎざの形は、直らない** |
| 口の外周が切り抜かれた形で浮く | 口を、輪郭ごと切り出している | 口の中は**外周に線なし**で、**一回り大きく**。口の周りの肌を別に描き、口と**同じ動きで**動かす。または、口の外周に、**肌色の縁（0.5〜1 mm 相当）**を足す |
| 頬の赤みが浮く | 縁が硬い | **縁を、ぼかして、中心から外へ、なだらかに消す**。最大の不透明度を、**20% 以下**に |

## 6. ChatGPT への依頼（コピーして使える文面）

### 6.1 共通の前置き
> 添付は、白い髪・犬耳（サモエドの立ち耳。顔の横に人間の耳はない）・青い目のキャラクター（人間ではなく、陶器のように滑らかな白い外装肌のヒューマノイドロボット）です。Live2D 用の、パーツ別の透明 PNG を作ってほしいです。
> - 絵柄・色・線の太さは、添付の基準画像（`upper-body-1x.png`）と同じにする。デザインを変えない。
> - 肌の色：明部 RGB 約 (252,249,250)、影 約 (220,207,220)。ベージュ・黄み・桃色・血色は、加えない。
> - 線の色は、次の3種類だけで、すべて基準画像から採取した色にする：肌の外周（RGB 約 (117,102,120)、幅 約 3px）、髪の外周（青紫）、目と口の内側。
> - 背景は透明の PNG（最初からアルファ付きで出力する）。サイズは、基準の枠 1536×1536 と同じ正方形。位置と縮尺は、基準画像と同じにする（移動・拡大縮小・トリミングをしない）。
> - 毎回、基準画像（`upper-body-1x.png`）と、採用済みのパーツを参照として添える。目の形・房の本数・分け目・耳の角度を維持する。
> - **他のパーツと重なる端は、輪郭線を描かず、塗りだけにして、20〜40px 大きく描き足す**。切り口を、平らにしない。
> - 描かないものは、透明にする。

### 6.2 素材ごとの依頼
1. **頭の素肌ベース**：「顔の素肌だけ。額・こめかみ・頬・顎を、髪・耳に隠れる部分まで描き、首・のどまで、一続きで描く。目・鼻・口・眉・頬の赤み・内部の線は描かない。顎の下は、見上げたとき顎の裏が見える分、大きめに。」
2. **首**：「口の高さから、首輪の下まで。左右と下に余白（各 40px）を足す。首の前面の影は、顎の下だけ、薄く。肩の素肌に、重なるように。」
3. **頭頂の髪と、髪の下地**：「前髪の裏・分け目の下の、頭の丸い形に沿った髪の下地。髪の色。ドームを、円盤として、目立たせない。」
4. **耳の裏側・付け根**：「犬耳（サモエドの立ち耳）の裏（外側の毛並み）と、頭に付く付け根の面。耳の根元の房は、耳に付ける。画像の端に、接しないように。」
5. **口の中**：「口腔・舌・歯だけ。輪郭線なし。元より一回り大きく。閉・小・大の3段階。口の周りの肌は、別の画像に。」
6. **頬の赤み**：「赤みだけ。最大の不透明度 20%。縁は、なだらかに消す。」
7. **髪の分割**：「前髪／左右の横髪／後ろ髪／アホ毛を、別々の透明 PNG に。各パーツは、髪の根元の、隠れる部分まで描く。」
8. **毛皮の襟**：「毛皮の襟だけ（胴体なし）。裏側（体に隠れる側）も描く。」
9. **目（左右）**：「白目・虹彩（ハイライトは別の画像）・まつ毛・二重を、別々に。倍の解像度。開・半・閉の3状態。」
10. **角度ごとの差し替え（必要なら）**：「顎の裏／耳の裏／頭頂の髪を、向き ±30° で。**素肌ベース（1）と同じ色・線・位置**。つなぎ目は、素肌ベースの下に潜らせる。」

### 6.3 進め方（ChatGPT の回答を反映、2026-10-10）
ChatGPT の回答：透明 PNG は直接出せる。最大サイズは、このチャットでは不明（API では各辺 3840 以下・16 の倍数・正方形で約 2880 まで。高解像度は実験的）。画素単位の位置合わせ、色の完全一致、余白幅、デザインの保持は、保証されない。複数パーツは 1 枚ずつ依頼する。生成による 2 倍化は、輪郭線・色・房が変わるおそれがある。

これを受けた方針：
1. **キャンバスは 1536×1536 のまま、1 枚ずつ依頼**する。3072 での直接生成は前提にしない。
2. **位置・色・縁の補正は、こちらで行う**（半透明の重ね合わせで位置を合わせ、領域ごとに色を補正）。生成結果は「形と塗りの素材」として受け取る。
3. **Codex の実測（2026-10-10）**：画像生成は、1536・2048・2304・2880 を指定しても、**保存結果はすべて 1254×1254**。透明 PNG は出せる（内部に半透明の画素が混ざるので、検証が要る）。参照を入れた編集は、**編集対象外の輪郭も変わる**。基準画像 `upper-body-1x.png` の実寸は 1086×1448。したがって、**「高解像度で出してもらう」は成立しない**。代わりに、次の方法を使う：
   - **パーツごとに、狭い範囲を切り出して依頼する**（例：顔だけ、耳だけ、首だけ）。切り出した範囲が小さいほど、1254 px あたりの細かさが上がる。出力は、こちらで元の座標に戻す。
   - **編集の結果は、対象の範囲のマスク内だけを採用する**（こちらでマスクして合成）。範囲外の変化は捨てる。
   - 位置・縮尺・色は、こちらの補正で合わせる（2.）。
4. 依頼の順番（1 枚ずつ、採用したら基準に加える）：
   ①基準絵の縁を整える（耳・髪・毛皮のぎざぎざ） → ②顔の素肌ベース＋首 → ③耳・耳の裏・後ろ髪 → ④横髪・前髪・頭頂の髪 → ⑤目・口の細部（口の中、周りの肌）→ ⑥頬の赤み → ⑦毛皮の襟。
5. 生成結果を次の依頼の唯一の参照にしない（変化が蓄積する）。**元の基準画像を毎回添える**。

Codex の実行条件：画像生成は一般の利用枠を消費する。生成ツールは `.codex/generated_images/` に自動保存する（新フォルダだけには限定できない）。「1 枚生成→検証→報告→確認待ち」で止まれる。不合格の画像を採用素材にせず、理由付きで報告できる（生成画像のチャット表示は避けられない）。検証コードは `assets/ciel/generated/v4-capability-test/verify.py`、実測は同フォルダの `report.json`。

### 6.4 受け取ったときの確認項目
- 端が、ぎざぎざしていないか。黒・灰色の背景に重ねて、縁に白残りがないか。
- 基準画像と半透明で重ねて、位置・縮尺がずれていないか（ずれは、こちらで補正する）。
- 肌の明部・影を複数点で測り、指定の色に近いか（外れていれば、領域ごとに補正する）。
- 線の色が、3種類だけで、基準から採取した色と一致するか。
- 肌ベース・首・体の、色の連続（つなぎ目に、段差がないか）。
- 切り口が、平らでなく、重なる分、大きく描かれているか。
- 画像の端に、絵が接していないか（切れていないか）。
- 描かないはずのもの（髪、体、背景）が、残っていないか。

- 3（頭頂の髪）・（旧）C・K・H・E のうち、新素材に置き換わったものを、`parts/underlayers/` から外す。
- 首を Body_Base から切り離す（`bake-chin-into-body.py` の焼き込みをやめる）。
- 重なり順：肌→首→体→毛皮→横髪→前髪。
- 肌色の統一：`_porcelain` を正にして、古い版を整理する（引き継ぎ資料 3.3）。
- 新素材が来たら、`build-*.py` を、新しい入力に合わせて直し、Cubism へ。
